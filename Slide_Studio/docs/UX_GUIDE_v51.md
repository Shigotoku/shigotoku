# v5.1 UX principles

- Keep the left sidebar: it is the user's mental map.
- Show one primary task in the center: create a presentation.
- Advanced settings stay hidden until requested.
- Use neutral white/charcoal with one teal accent; avoid gradient-heavy "AI" visuals.
- Use contextual guidance rather than permanent instructions.
- Keep the workflow to four visible steps.
- Make generated slides visible immediately and editable in Google Slides with one click.
- Preserve information density suitable for 1366x768 through 4K displays.
- Never rely on color alone for status.
- Keep terminology consistent: Project / Style / Reference / Slides.
