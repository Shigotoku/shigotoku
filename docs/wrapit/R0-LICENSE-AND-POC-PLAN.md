# WrapIt R0: ライセンス確認と PoC 計画

- 日付: 2026-11-27
- 目的: 方式(レンダラー・テンプレート)を、**実測と契約条件**で決める。本番・既存製品には触れない。

## 1. ライセンス確認の結果(公式ドキュメント 2026-11-27 時点)

出典: [License & Pricing](https://www.remotion.dev/docs/license/pricing) / [License FAQ](https://www.remotion.dev/docs/license/faq.md) / [Terms v5.0](https://www.remotion.dev/docs/terms)

| 項目 | 内容 |
|------|------|
| 無料ライセンス | 個人、または**組織全体で3人以下**。商用・SaaS・自動化も機能制限なしで利用可 |
| 4人以上の組織 | Company License が必要。一部の人だけが使っていても、**組織全体の人数**で判定 |
| Remotion for Automators | 自動レンダリング(`renderMedia()` 等を呼ぶコード)は **1 レンダー $0.01、$10 単位、最小 $100/月**。Player を Web 埋め込みで使う場合も Company License では対象 |
| Remotion for Creators | 手動で動画を作る人が1席 $25/月(自動化には不要) |
| 数え方 | 成功したレンダーのみ。サーバー・クライアント側は合算 |
| インフラ費 | Remotion は自分のクラウド(AWS/GCP/Azure)で動かす前提。**インフラ費は別**(ライセンス料に含まれない) |
| Enterprise | $500/月〜 |

**判断が必要な点(R0 の最初に確定)**
1. Shigotoku 組織の人数の数え方(役員・業務委託・グループ会社の扱い)。無料条件(3人以下)に該当するか。
2. 該当しない場合のコスト感: 例えば月1,000本レンダーで最小 $100/月に収まる(1,000 × $0.01 = $10 だが最小 $100)。**1本あたり原価にライセンス料を含めて試算**する。
3. Remotion の規約が将来変わる可能性。**条件の控えをスクリーンショットではなく URL+確認日で台帳化**する。

→ ライセンスが事業に合わない場合は、代替(OSS 系・FFmpeg 系・ブラウザ内レンダー)で PoC を行う。

## 3. PoC の方式

テストシナリオは同一(**採用動画 25 秒、1080×1920、30fps**): 冒頭に写真3枚、見出し、本文を段階表示、縦書きの一部、CTA、BGM。

| PoC | 方式 | 見るもの |
|-----|------|----------|
| P-A | Remotion(ローカルで `renderMedia`)→ Cloud Run Job 想定 | 日本語組版の品質、生成時間、メモリ、プレビューと出力の一致 |
| P-D | ブラウザ内レンダー(WebCodecs 等) | 品質、端末差、所要時間。**サーバー原価ゼロの可否** |
| P-B/C | ライセンス不可の場合のみ(OSS 系 / FFmpeg) | 同上 |

### 判定表(各 PoC で記入)

| 項目 | 合格目安(実測で改定) |
|------|------------------------|
| 日本語(縦書き・禁則・段階表示) | 重大な崩れゼロ |
| 生成時間 | p95 180 秒以内を目標 |
| メモリ/CPU | Cloud Run Job の現実的な設定で完了 |
| 1本あたり原価 | 実測。ライセンス料・AI・保管を含める |
| プレビューと出力の一致 | 同一コンポジション |
| ライセンス | 商用・SaaS 可、台帳に記録 |

### 実施ルール
- PoC は**リポジトリ外の別ディレクトリ**、または未追跡の `wrapit/poc/` で行い、**既存製品のコード・デプロイ設定に触れない**。
- 素材はテスト用のみ。実患者・実顧客のデータは使わない。
- PoC の結果は ADR-0004(レンダリング方式)として記録してからR1に進む。
