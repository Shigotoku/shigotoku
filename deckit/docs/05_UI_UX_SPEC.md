# UI / UX Specification

## Product feel
calm / professional / minimal / Google-compatible / not AI-neon。

## Sidebar
Dark sidebar conceptを維持。New presentation、Projects、Styles、References、optional Drive、Guide、Settings。

## Composer
4 steps: Sources / Outline / Generate / Edit。

## Preview
thumbnail rail + 16:9 preview + version + Open in Slides。

## UX rules
- Modalは即時。server await禁止
- Skeleton first, data later
- white page禁止
- 全actionにresponse
- Advancedはcollapsed
- Folder IDをnormal userへ見せない
- Primary actionはstateごとに1つ
- local UIはbackend障害でも動く

## Design
white/charcoal/muted teal。控えめshadow/round。1366×768〜4K。

## Accessibility
keyboard focus、control height約40px、ARIA dialog、Esc close、logical tab order、color-only禁止。
