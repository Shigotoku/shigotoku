## ADR-001: PreDeckの本質を「意思決定突破エンジン」とする

| 項目 | 内容 |
|---|---|
| 状態 | 採用 |
| 決定日 | 2026-05-08 |
| 判断 | PreDeckはスピーチ練習アプリではなく、意思決定を「通す」ためのコーチングアプリとして設計する |

## ADR-003: 5ステップUIを主導線にする

| 項目 | 内容 |
|---|---|
| 状態 | 採用 |
| 判断 | 画面上の主導線は「スライド設定 → 録音 → 文字おこし確認 → 原稿改善 → 練習」の5ステップにする |
| 代替案 | 「話す → 直す → もう一度話す」を主コピーにする反復ループUI |
| 採用理由 | 初回ユーザーにとって次の操作が明確で、5ステップを1ラウンドとして反復する方が理解しやすい |
| 影響 | ナビゲーション、オンボーディング、チュートリアル、workflow guardsは5ステップ基準で実装する |

参照元:
- PreDeck_統合設計書_20260508.md

## ADR-004: 2.5ペイン・ワークベンチを採用する

| 項目 | 内容 |
|---|---|
| 状態 | 採用 |
| 判断 | 左: スライド、中央: 作業、右: AIコーチ（折りたたみ可能）の2.5ペインにする |
| 代替案 | 単純2ペイン、完全3ペイン |

| 項目 | 条件 |
