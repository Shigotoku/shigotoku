## 凡例

### 対応スコープ
- **L**: レガシー版（`プレデキ/` 直下、FastAPI + ブラウザ）でも実装する／された
- **V2**: 新MVP `プレデキ_ver2.0/`（Tauri 2 + React + sidecar）で実装する／された
- **L→V2**: レガシー版で実装済の機能を ver2.0 へ移植する必要あり
- **V2優先**: ver2.0 で本実装する。レガシー版へのバックポートは原則しない
- **両方並行**: 当面はレガシー版でも継続更新する

### 進捗
- 🟢 実装済 / ⚪ 未実装 / 🟡 一部実装 / 🔴 ブロッカーあり

## 🔴 Phase 2〜3 相当（比較的近い目標）

### WPMグラフのスライド別可視化
- **要件**: Ver7.0 §4-4「WPMペースグラフ」
- **現状**:
  - L: 全体WPMのみ表示。スライド別バーグラフが未実装
  - V2: UI 雛形のみ
- **スコープ**: 両方並行
- **実装メモ**: `slide_timings` データは既にバックエンドに存在。`runSpeechAnalysis()` にスライド別グラフ描画を追加

### 圧迫ピッチモードのスコアリング
- **要件**: Ver7.0 §4-5「圧迫ピッチモード」
- **現状**:
  - L: チャット形式Q&Aのみ。採点機能が未実装
  - V2: UI 雛形のみ
- **スコープ**: V2優先（圧迫質問生成は LLM JSON Schema 強制と相性が良いため）
- **採点項目**:
  - 反応速度（割り込みへの即応力）
  - 論理維持力（回答の論理的整合性）
  - 再開スムーズ度（回答後、元のプレゼンに戻れるか）
  - 感情コントロール（動揺せず堂々と対応できたか）

### 自信曲線（弱気ワード推移グラフ）
- **要件**: Ver7.0 成長可視化レイヤー「自信曲線」
- **現状**: L/V2 とも未実装
- **スコープ**: 両方並行
- **実装メモ**: イテレーションごとに `hedging_words` 件数を保存し折れ線グラフで表示

### 最初 vs 最新の練習比較表示
- **要件**: Ver7.0 成長可視化レイヤー「本番直前比較」
- **現状**: L/V2 とも未実装
- **スコープ**: 両方並行
- **内容**: 「第1回の原稿 vs 最新回の原稿」の差分・スコア差を並べて表示

### 構造診断のピラミッド可視化図
- **要件**: Ver7.0 §4-2「構造診断エンジン」
- **現状**:
  - L: テキスト表示のみ
  - V2: API 雛形（`/api/llm/diagnose-structure`）あり、可視化は未実装
- **スコープ**: 両方並行
- **内容**: 導入→問題提起→解決策→根拠→CTA のピラミッド構造をSVG/CSSで視覚化 + 各層のスコアを色分け

### 勝率スコアのフィードバック収集機能
- **要件**: Ver7.0 §4-3「スコア校正戦略 Phase 2」
- **現状**: L/V2 とも未実装
- **スコープ**: V2優先（DBスキーマ拡張が必要）
- **内容**: 「このピッチは通った / 落ちた」をユーザーが記録 → 成功パターンのコーパス蓄積

### ピッチチェックリスト本実装（A〜Dランク）
- **要件**: Ver7.0 §4-3
- **現状**:
  - L: 🟢 実装済（A〜Dランク表示）
  - V2: ⚪ UI 雛形のみ
- **スコープ**: L→V2（移植）

## 🟡 Phase 3〜4 相当（中期目標）

### 英語文化適応解析
- **要件**: Ver7.0 §5-7「英語文化適応解析」
- **スコープ**: V2優先
- **内容**: 英語原稿に対して英語圏のプレゼン基準で問題を検出
  - 主張の弱さ（結論が曖昧）
  - 具体性不足（抽象的すぎる表現）
  - 自己主張不足（成果のアピールが足りない）
  - 回りくどさ（日本語的な婉曲表現の残存）

### 崩し言い換えモード（フォーマル⇄カジュアル切替）
- **要件**: Ver7.0 §5-5「崩し言い換えモード」
- **スコープ**: V2優先
- **内容**: 同じ内容を4段階のトーンで言い換え
  - Very formal（外交・公式）
  - Business natural（一般ビジネス）
  - Startup casual（テック業界）
  - Conversational（日常会話）

### 英語即応力トレーニング
- **要件**: Ver7.0 §5-6「英語即応力トレーニング」
- **スコープ**: V2優先
- **内容**: 英語での圧迫質問に即座に答える訓練
  - 例: "Wait, I don't understand your market size."
  - 例: "How is this different from [competitor]?"

### 音声追従ハイライト（カラオケ式）
- **要件**: Ver7.0 共通サポート機能「スマート・プロンプター」
- **現状**:
  - L: 音声追従スクロールは実装済。単語レベルハイライトが未実装
  - V2: 未実装
- **スコープ**: 両方並行
- **実装メモ**: faster-whisper の `word_timestamps=True` を利用すれば V2 では精度向上が見込める（Ver6.0 案の Web Speech API は §1.2 で禁止）

### PowerPoint / Keynote 連携強化
- **要件**: Ver7.0 §5-4
- **現状**:
  - L: PDF のみ対応
  - V2: 🟢 PNG 手動アップロード（2026-05-09 結線済）。自動変換は未実装
- **スコープ**: 両方並行
- **優先度**: PowerPoint（Phase 2）、Keynote（Phase 2）、Figma/Canva（Phase 4）

### UI多言語対応
- **要件**: Ver7.0 §9 / §11.4
- **Phase 3**: 英語UI
- **Phase 4+**: 中国語（簡体/繁体）、韓国語
- **スコープ**: V2優先（i18n 基盤を最初から組み込む）

## ⚫ Phase 4 以降（長期目標・大規模実装）

### カメラ解析（オプション機能・明示的同意制）
- **要件**: Ver7.0 §4-6「カメラ解析」
- **スコープ**: V2優先
- **内容**:
  - カメラ目線保持率（原稿ばかり見ていないか）
  - 原稿依存率
  - 表情感情分類（緊張・自信・無表情）
  - ジェスチャー解析
- **注意**: デフォルトOFF。明示的なオプトイン必須。**相手の表情解析は実装しない**（GDPR/ToS リスク、Ver7.0 §11 禁止実装リスト）

### 発音トレーニング
- **要件**: Ver7.0 §5-3「発音トレーニング」
- **スコープ**: V2優先（独立プロダクト級）
- **内容**: 単語 → 文 → 通し練習の3段階。American/British切替、シャドーイングモード

### 単語帳システム（プレゼン特化）
- **要件**: Ver7.0 §5-4
- **スコープ**: V2優先
- **内容**: ワンクリック登録、自動例文生成、音声再生、忘却曲線ベースの復習リマインド

### URL共有・非同期フィードバック
- **要件**: Ver7.0 §5-1
- **スコープ**: V2優先（Next.js Web 側で実装）
- **内容**: 練習録音＋AIスコアを専用URLで共有。閲覧者がタイムラインにコメント可能
- **備考**: バイラルループの核となる機能

### Stripe決済・プラン制限
- **要件**: Ver7.0 §6 / Q-B-001/002
- **スコープ**: V2優先（Web 側で実装）
- **プラン構成**: Free / Lite（500〜800円）/ DIY（1,200〜1,800円）/ Smart（2,500〜3,000円）/ Enterprise
- **承認**: 人間承認必須

### Chrome拡張（Google Slides連動）
- **要件**: Ver7.0 §3-1（WXT + React 候補）
- **スコープ**: V2優先
- **内容**: Google Slidesのサイドバーで1スライドAI修正・簡易プレビュー → ローカルアプリへの誘導

### Tauri デスクトップアプリ化
- **現状**: ✅ ver2.0 で実装中（Phase 1 末で MSI 配布検証予定）
- **スコープ**: V2のみ
- **備考**: レガシー版（FastAPI + ブラウザ）から ver2.0 への移行で達成

### 本番リアルタイムアシスト
- **要件**: Ver7.0 §5-3
- **スコープ**: V2優先（Phase 3 以降）
- **内容**: Zoom/Teams本番中に透明ウィジェットとして常駐
  - ペースアラート（「少し早口になっています」）
  - 時間リマインダー（「残り2分です」）
  - 台本リマインダー（半透明表示）
  - キーメッセージ表示
- **注意**: 相手の映像解析は実装しない

### Enterprise チーム学習機能
- **要件**: Ver7.0 §5-2
- **スコープ**: V2優先（Enterprise 商談時）
- **内容**: 社内の過去ピッチをアップロード → AIが企業固有の勝ちパターンを学習
