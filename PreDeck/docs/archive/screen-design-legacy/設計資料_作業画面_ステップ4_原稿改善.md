# 設計資料_作業画面_ステップ4_原稿改善

> 対象: 作業画面 ステップ④ 「原稿改善」
> HTML: `static/index.html` L501〜L610（右: `#content-4`）
> 主な関連JS関数: `requestImprovement()` / `requestImprovementStreaming()` / `togglePitchScorePanel()` / `runSpeechAnalysis()` / `switchScriptTab()` / `syncAiToUser()` / `copyScript()` / `downloadScript()` / `toggleSaveMenu()` / `showQRCode()`

---

## 1. 画面概要

文字おこし原稿をAIで改善し、ユーザー編集と並べて確認する画面。ピッチスコアの算出、差分比較、保存（テキスト/QR）まで行います。

```
┌─ 左: スライドパネル ─┬─ 右: #content-4 ──────────────────────────┐
│ （ステップ1と同じ）  │ <h2>④ 原稿改善</h2>                         │
│                    │ ▸ ←③文字おこし / ⑤練習→                     │
│                    │ ┌─ #ai-improve-action-row ───────────────┐ │
│                    │ │ #improve-status (実行中スピナー)         │ │
│                    │ │ #ai-improve-ready                       │ │
│                    │ │   [🤖 AI原稿改善を実行]                  │ │
│                    │ │   ai-improve-hint-text                  │ │
│                    │ └─────────────────────────────────────────┘ │
│                    │ .pitch-score-trigger-row                    │
│                    │   [🎯 ピッチスコアを確認] [🔄 再採点]         │
│                    │ #pitch-score-panel (展開可能)                │
│                    │ #diagnosis-panel (任意)                      │
│                    │ ── .script-toolbar ──                       │
│                    │   [📋 原稿確認 / 🔍 差分比較] (タブ)          │
│                    │   [🔄 AI→自分の原稿へ反映] [📋コピー][💾保存▾] │
│                    │ #panel-improved （左: ✏️自分 / 右: 🤖AI）    │
│                    │ #panel-diff      （差分ビュー）               │
└────────────────────┴─────────────────────────────────────────────┘
```

## 3. AI原稿改善 実行行 (`#ai-improve-action-row`)

### 3-1. 改善中ステータス (`#improve-status`)

|---|---|---|---|

### 3-2. 実行ボタン (`#ai-improve-ready`)

| 要素 | ID | 種別 | 内容 / 動作 |
|---|---|---|---|
| `[🤖 AI原稿改善を実行]` | `#btn-run-improvement` | ボタン (`btn btn-primary btn-improve-run`) | `requestImprovement()` を呼び `POST /api/improve-script` または `/api/improve-script-stream` で改善 |

## 4. ピッチスコア (`.pitch-score-trigger-row` + `#pitch-score-panel`)

| 要素 | ID | 種別 | 内容 / 動作 |
|---|---|---|---|

### 4-2. ピッチスコアパネル (`#pitch-score-panel`)

| 要素 | ID | 種別 | 内容 |
|---|---|---|---|
| ヘッダーラベル | — | テキスト | `🎯 ピッチスコア` |
| ランクバッジ | `#pitch-rank-badge.pitch-rank-badge` | バッジ | A〜D の総合ランク |
| `[✕]` | — | ボタン | パネルを閉じる |
| スコアバー（背景） | `.pitch-score-bar-bg` | バー枠 | — |

## 7. 改善原稿タブ (`#panel-improved`)

### 7-1. 分割レイアウト (`.script-split-pane`)

```
┌── 左: #user-script (.script-pane-user) ──┬── 右: #improved-script (.script-pane-ai) ──┐
│ ✏️ 自分の原稿                              │ 🤖 AI改善原稿                                │
│ 「文字おこしから自由に編集できます」          │ 「AIの提案（参照用）」                       │
│ contenteditable=true                     │ contenteditable=false                     │
└──────────────────────────────────────────┴───────────────────────────────────────────┘
```

| 要素 | ID | 種別 | 内容 / 動作 |
|---|---|---|---|
| ペインヘッダー（左） | — | テキスト | `✏️ 自分の原稿` / ヒント |
| ユーザー編集エリア | `#user-script` | `<div contenteditable="true">` | プレースホルダ「文字おこし内容が表示されます。自由に編集できます。」。練習モード（ステップ5）に渡される本文 |
| 区切り | `.script-pane-divider` | 装飾 | 縦線 |
| ペインヘッダー（右） | — | テキスト | `🤖 AI改善原稿` / ヒント |
| AI改善表示 | `#improved-script` | `<div contenteditable="false">` | AI改善結果。差分マーカー（`+追加` / `-削除`）がインライン強調表示 |

## 8. 差分比較タブ (`#panel-diff`)

| 要素 | ID | 種別 | 内容 |
|---|---|---|---|
| 凡例 | `.diff-legend` | コンテナ | `＋ 追加` / `－ 削除` / 補足 |
| 差分本文 | `#diff-view.script-content` | 表示エリア | 文字単位の差分（前回 vs AI改善 or 自分 vs AI） |

`switchScriptTab('diff')` 時に最新の差分を再計算して描画。

---

## 9. 関連API

| メソッド | エンドポイント | 用途 |
|---|---|---|
| POST | `/api/improve-script` | 同期版・原稿改善（小モデル/即時） |
| POST | `/api/improve-script-stream` | ストリーミング版（GPT-4o系の長文向け） |
| POST | `/api/analyze-speech` | ピッチスコア算出 |
| POST | `/api/convert-english` | 英語ピッチへの完全変換（場合により呼び出し） |
| PUT | `/api/sessions/{id}` | 改善原稿・ユーザー編集を保存 |

---

## 10. 状態 / 保存内容

| state | 内容 |
|---|---|
| `state.currentScript` | 現在のメイン原稿（`#user-script` のテキスト） |
| `state.improvedScript` | AI改善結果 |
| `state.previousTranscript` | 差分比較用の前回原稿 |
| `state.pitchScore` | スコア値、ランク、チェックリスト |

オートセーブ: 編集ペインのblur/inputで `PUT /api/sessions/{id}` を介して `iterations[]` に保存。
