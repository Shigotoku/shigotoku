# 設計資料_作業画面_ステップ2_録音

> 対象: 作業画面 ステップ② 「録音する」
> HTML: `static/index.html` L273〜L353（右: `#content-2`）
> 主な関連JS関数: `toggleRecording()` / `startRecording()` / `stopRecording()` / `discardRecording()` / `proceedToTranscribe()` / `prevSlide()` / `nextSlide()` / `renderTimingLog()` / `startRealtimeTranscript()`

---

## 1. 画面概要

スライドを表示しつつマイク録音を行う画面。録音中はスライド切替タイミングが自動でログされ、リアルタイム文字起こし（Web Speech API）も並走します。

```
┌─ 左: スライドパネル ─┬─ 右: #content-2 ─────────────────────────┐
│ （ステップ1と同じ）  │ <h2>② 録音する</h2>                       │
│ ◀ N/M ▶            │ ▸ ←①スライド  ▸ ③文字おこし→             │
│                    │ ─────────────────────────────────────     │
│                    │ #iteration-info（第N回練習バッジ・任意）    │
│                    │ #record-slide-script（スライド別原稿）      │
│                    │ ┌── .record-area ────────────────────────┐│
│                    │ │ #timer-display 0:00                    ││
│                    │ │ "録音時間"                              ││
│                    │ │ [🎙️ 録音開始 / ⏹️ 録音停止]            ││
│                    │ │ #volume-wrap 音量バー                   ││
│                    │ │ #post-record-actions:                   ││
│                    │ │   🗑️ 削除して録り直す                   ││
│                    │ │   ③ 文字おこしへ →                     ││
│                    │ └────────────────────────────────────────┘│
│                    │ #realtime-transcript-area                  │
│                    │ #timing-log（スライド切替ログ）             │
│                    │ .kbd-help-bar (← → / Space)              │
└────────────────────┴─────────────────────────────────────────┘
```

## 3. セッション復元ナビ（非表示要素）

`#session-resume-nav` （`display:none` のままJS参照用）。
過去セッション復元時に、保存済みの文字おこし／改善原稿／練習原稿があればステップ3〜5へジャンプする `data-resume-step` ボタンを `_updateResumeNav()` が制御します。

| 要素 | `data-resume-step` | 動作 |
|---|---|---|
| ボタン | `3` | `resumeGoToStep(3)`（文字おこし復元） |
| ボタン | `4` | `resumeGoToStep(4)`（AI改善原稿復元） |
| ボタン | `5` | `resumeGoToStep(5)`（練習用原稿復元） |

## 6. 録音操作エリア (`.record-area`)

### 6-1. タイマー表示

| 要素 | ID | 内容 |
|---|---|---|
| 大きい数字 | `#timer-display` | 録音経過時間 `M:SS`、初期値 `0:00`。`updateTimer()` で1秒ごとに更新 |
| サブラベル | `.timer-sublabel` | `録音時間` |

### 6-2. 録音ボタン (`#btn-record`)

| 状態 | クラス | ラベル (`#record-label`) | アイコン (`#record-dot`) | 動作 |
|---|---|---|---|---|
| 未録音 | `btn btn-record` | `🎙️ 録音開始` | 灰色ドット | クリックで `toggleRecording()` → `startRecording()` |
| 録音中 | `btn btn-record recording` | `⏹️ 録音停止` | 赤点滅 | クリックで `toggleRecording()` → `stopRecording()` |
| 停止後 | `disabled` | `🎙️ 録音開始` | 灰色 | 押下不可（削除 or 進むのみ） |

`Space` キーでも開始/停止が可能（`.kbd-help-bar` に表示）。

### 6-3. 音量メーター (`#volume-wrap`)

録音中のみ `display:flex` で表示。

| 要素 | クラス | 内容 |
|---|---|---|
| 背景バー | `.volume-bar-bg` | バー枠 |
| 充填バー | `#volume-fill .volume-bar-fill` | リアルタイム音量で幅 0〜100% |
| ラベル | `.volume-label` | `音量` |

### 6-4. 録音停止後アクション (`#post-record-actions`)

録音停止後に `display:flex` で出現。

| 要素 | 種別 | 内容 / 動作 |
|---|---|---|
| `🗑️ 削除して録り直す` | ボタン (`btn btn-ghost btn-discard`) | `discardRecording()` で録音データ・タイミングログを破棄 |
| `③ 文字おこしへ →` | ボタン (`btn btn-primary btn-proceed-transcribe`) | `proceedToTranscribe()` で `POST /api/transcribe` を実行しステップ3へ遷移 |

## 7. リアルタイム文字起こし (`#realtime-transcript-area`)

録音中のWeb Speech APIによる暫定文字起こし表示。

| 要素 | ID | 種別 | 内容 |
|---|---|---|---|
| ヘッダー | `.rta-header` | コンテナ | `🎤 リアルタイム文字起こし` |
| ステータス | `#rta-status` | テキスト | `認識中...` / 言語切替時の表示など |
| 確定テキスト | `#rta-final` | `<span>` | 認識確定済み |
| 暫定テキスト | `#rta-interim.rta-interim` | `<span>` | 灰色で暫定表示 |

`startRealtimeTranscript()` / `stopRealtimeTranscript()` で開始・終了。
ブラウザがWeb Speech API非対応の場合は表示されません。

---

## 8. スライド切替ログ (`#timing-log`)

録音中に `←` / `→` でスライドを切り替えた時刻を `state.slideTimings` に追記し、表示します。
表示には `renderTimingLog()` を使用。

| 要素 | ID | 種別 | 内容 |
|---|---|---|---|
| タイトル | `.timing-log-title` | テキスト | `🗂 スライド切り替えログ` |
| ログコンテナ | `#timing-log-items` | コンテナ | 切替記録のチップ。空の場合 `録音中にスライドを切り替えるとここに記録されます` を表示 |

各ログチップは `スライドN @ M:SS` 形式（実装は `renderTimingLog`）。

---

## 9. キーボードショートカット (`.kbd-help-bar`)

| ショートカット | 機能 |
|---|---|
| `←` / `→` | スライド切替（`prevSlide()` / `nextSlide()`）。録音中ならタイミングログに自動記録 |
| `Space` | 録音 開始 / 停止（`toggleRecording()`） |

---

## 10. 状態 / 内部データ

| state | 設定タイミング | 内容 |
|---|---|---|
| `state.isRecording` | start/stop | 録音中フラグ |
| `state.audioChunks[]` | MediaRecorder.ondataavailable | webm音声チャンク |
| `state.mediaRecorder` | start | MediaRecorderインスタンス |
| `state.mediaStream` | start | マイクストリーム（stop時に必ず解放） |
| `state.recordingStartTime` | start | 開始タイムスタンプ |
| `state.slideTimings[]` | start, prev/nextSlide | `{ slide, time }` 配列 |
| `state.timerInterval` | start | `setInterval` ハンドル |
| `state._recordedBlob` | stop | webm Blob（次ステップへの入力） |
| `state._lastRealtimeText` | stop | リアルタイム文字起こしの最終確定文 |

## 11. 関連API

| メソッド | エンドポイント | 用途 |
|---|---|---|
| POST | `/api/transcribe` | `proceedToTranscribe()` から呼び出し。webm音声→テキスト変換（ローカルWhisper / OpenAI API） |
| PUT | `/api/sessions/{id}` | 録音タイミング・現在ステップを保存（オートセーブ） |
