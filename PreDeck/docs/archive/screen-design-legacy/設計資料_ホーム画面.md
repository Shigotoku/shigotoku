# 設計資料_ホーム画面

> 対象: `#screen-home`（`static/index.html` L29〜L57）
> 関連JS関数: `showHome()` / `loadSessions()` / `createNewSession()` / `loadSession()` / `deleteSession()`

---

## 1. 画面概要

ホーム画面はアプリ起動直後に表示されるランディング兼セッション一覧画面です。
ヒーローエリア（ブランド紹介＋新規セッション作成）と、過去セッション一覧の2セクションで構成されています。

```
┌─ #screen-home ─────────────────────────────┐
│ .home-container                            │
│  ┌── .home-hero ──────────────────────┐    │
│  │ [ロゴ + プレデキ]                    │    │
│  │ 話すだけで、プレゼンできてく。       │    │
│  │ [説明文]                            │    │
│  │ 🤖 📊 💪 🎯（特徴チップ4つ）         │    │
│  │ ┌─ ✨ 新しいセッションを開始 ─┐     │    │
│  │ └────────────────────────────┘     │    │
│  └────────────────────────────────────┘    │
│                                            │
│  ┌── .session-list-section ───────────┐    │
│  │ 📋 過去のセッション                 │    │
│  │ #session-list （カード or 空状態）   │    │
│  └────────────────────────────────────┘    │
└────────────────────────────────────────────┘
```

---

## 2. ヒーローエリア (`.home-hero`)

| 要素 | 種別 | 表示内容 | 動作 |
|---|---|---|---|
| `.hero-brand .hero-logo-img` | 画像 | `/static/logo.png` | 装飾のみ |
| `.hero-brand .hero-brand-name` | テキスト | `プレデキ` | 装飾のみ |
| `<h2>` キャッチコピー | テキスト | `話すだけで、プレゼンできてく。` | 装飾のみ |
| 説明文 `<p>` | テキスト | スライドアップロード→録音→AI改善→再練習のサイクル説明 | 装飾のみ |
| `.hero-features` | チップ群（装飾） | `🤖 AI原稿改善` `📊 WPM解析` `💪 弱気ワード検出` `🎯 ピッチスコア` | 装飾のみ |
| `✨ 新しいセッションを開始` | ボタン (`btn btn-primary btn-large`) | `✨ 新しいセッションを開始` | `createNewSession()` を呼び、セッションID付きで `#screen-work` のステップ1へ遷移 |

### `createNewSession()` の動作（要約）
1. タイトル `セッション {現在日時}` で `POST /api/sessions` を実行。
2. レスポンスのセッションを `openSession()` に渡す。
3. `state.session` に保存→ `switchScreen('work')` で作業画面に切替→ステップ1表示。

---

## 3. 過去セッション一覧 (`.session-list-section`)

| 要素 | 種別 | 役割 |
|---|---|---|
| `<h3>📋 過去のセッション` | 見出し | セクション見出し |
| `#session-list` | コンテナ | セッションカードを動的描画。初期は `<div class="empty-state">セッションがまだありません</div>` |

### 3-1. 表示状態

`loadSessions()` （`GET /api/sessions`）の結果により、以下3パターンのいずれかが描画されます。

| 状態 | 表示 |
|---|---|
| 読み込み中 | `<div class="empty-state"><div class="spinner">…</div>読み込み中...</div>` |
| 0件 | `<div class="empty-state">セッションがまだありません</div>` |
| 1件以上 | `.session-card` を件数分繰り返し |
| 失敗 | `<div class="empty-state">読み込みに失敗しました</div>` |

### 3-2. セッションカード (`.session-card`)

```
┌─ .session-card  (onclick=loadSession) ─────────────────┐
│ .session-info                       │ .session-actions │
│  .session-title    例: 製品紹介ピッチ │ 🗑️ 削除ボタン     │
│  .session-meta                       │                 │
│    更新: 2026-05-01 18:24            │                 │
│    [3回練習済み]                      │                 │
│    [Aランク 82pt]（あれば）           │                 │
└────────────────────────────────────────────────────────┘
```

| 要素 | 種別 | 内容 / 動作 |
|---|---|---|
| カード全体 | クリック領域 | `loadSession(id)` を呼び、対象セッションを復元して作業画面へ |
| `.session-title` | テキスト | `session.title`（無題のときは「無題」） |
| `.session-meta` 内「更新」 | テキスト | `formatDate(session.updated_at)` |
| `.session-iterations` | バッジ | `{n}回練習済み` |
| `.session-score rank-{a/b/c/d}` | バッジ | 直近の `latest_rank` と `latest_score` を表示（無い場合は非表示） |
| 🗑️ ボタン (`.session-actions .btn-ghost`) | ボタン | `event.stopPropagation()` でカードクリック抑止 → `deleteSession(id)`。確認ダイアログ後に `DELETE /api/sessions/{id}`、成功でトースト+再ロード |

### 3-3. セッション復元時の挙動 (`openSession`)

カードクリック後の `openSession(session)` で次の状態を復元します:

- セッションタイトル → `#session-title`
- 目的タイプ → `.target-btn` の `active`
- 目標時間 → `#target-minutes` / `#target-seconds`
- スライド → 復元してビューア表示
- 過去原稿（文字おこし／AI改善／ユーザー編集）→ `state.restored*`
- PPTXソースファイル → `state.pptxOriginalFile`
- 表示ステップ → スライドが復元されていれば②録音、無ければ①スライド設定

復元時はステップ2以降の `#session-resume-nav` のボタン（`data-resume-step`）が `resumeGoToStep(n)` で各ステップにジャンプし、保存済みデータを画面に注入します。

## 4. 関連API

| メソッド | エンドポイント | 用途 |
|---|---|---|
| GET | `/api/sessions` | 一覧取得（`loadSessions()`） |
| POST | `/api/sessions` | 新規セッション作成（`createNewSession()`） |
| GET | `/api/sessions/{id}` | 詳細取得（`loadSession()`） |
| DELETE | `/api/sessions/{id}` | 削除（`deleteSession()`） |

---

## 5. 画面遷移サマリー

| トリガー | 遷移先 |
|---|---|
| `✨ 新しいセッションを開始` | 作業画面 ステップ1（スライド未アップロード状態） |
| セッションカードクリック | 作業画面（保存ステップに応じて自動位置決め） |
| 🗑️ クリック → 確認OK | 一覧から該当カードが消え、再ロード |
