# 設計資料_作業画面_ステップ5_練習モード

> 対象: 作業画面 ステップ⑤ 「練習モード」
> HTML: `static/index.html` L612〜L730（右: `#content-5`）+ 左パネルの `#practice-script-panel`
> 主な関連JS関数: `setupPracticeStep()` / `toggleTeleprompterMode()` / `toggleTpScroll()` / `toggleVoiceFollow()` / `setTpSpeed()` / `changeTpFontSize()` / `resetTp()` / `updateTpProgress()` / `toggleSlideScript()` / `startNextIteration()` / `startPressureMode()` / `closePressureMode()` / `sendPressureAnswer()` / `exportSessionReport()` / `finishSession()`

---

## 1. 画面概要

改善された原稿を見ながら、自分の言葉でプレゼン練習を行う最終ステップ。スライド連動の原稿表示、テレプロンプター（自動スクロール+声追従）、圧迫ピッチモード（厳しい質問のシミュレーション）、成長グラフ、レポート出力までを担います。

```
┌─ 左パネル ─────────────┬─ 右: #content-5 ─────────────────────────┐
│ スライドビューア + #practice-script-panel │ <h2>⑤ 練習モード</h2>      │
│ 📖 発表原稿（参考）        │ ▸ ←④原稿改善                              │
│ #practice-script-text     │ 説明文                                   │
│                          │ #growth-chart-section（成長記録）         │
│                          │ #practice-score-summary（4指標サマリー）  │
│                          │ #slide-script-box（スライド連動原稿）      │
│                          │ .tp-toggle-bar [📜 スクロール原稿モード]   │
│                          │ #tp-normal-view 通常表示                  │
│                          │ #tp-mode-view  テレプロンプター表示        │
│                          │ #pressure-mode-section 圧迫ピッチモード   │
│                          │ .step-actions: 4ボタン                    │
└──────────────────────────┴─────────────────────────────────────────┘
```

## 10. 圧迫ピッチモード (`#pressure-mode-section`)

`startPressureMode()` で表示開始。AIが厳しい投資家・面接官に扮して質問するチャットUI。

### 10-1. ヘッダー (`.pressure-mode-header`)

| 要素 | クラス | 種別 | 内容 / 動作 |
|---|---|---|---|
| タイトル | `.pressure-mode-title` | テキスト | `💥 圧迫ピッチモード` |
| 説明 | `.pressure-mode-desc` | テキスト | `AIが厳しい投資家・面接官に扮して質問します` |
| `[✕ 終了]` | ボタン (`btn btn-sm btn-ghost`) | — | `closePressureMode()` |

### 10-2. チャット表示 (`#pressure-chat`)

| 要素 | ID | 種別 | 内容 |
|---|---|---|---|
| チャット履歴 | `#pressure-chat.pressure-chat` | コンテナ | AI（質問者）/ ユーザー（回答）の吹き出しを順次追加 |

### 10-3. 入力 (`.pressure-input-row`)

| 要素 | ID | 種別 | 内容 / 動作 |
|---|---|---|---|
| 回答入力 | `#pressure-answer-input` | `<input type="text">` (`input-field`) | プレースホルダ「答えを入力して Enter…」。Enterで送信 |
| `[送信]` | ボタン (`btn btn-primary btn-sm`) | — | `sendPressureAnswer()`：`POST /api/pressure-pitch` に送信し次の質問を取得 |

## 12. 関連API

| メソッド | エンドポイント | 用途 |
|---|---|---|
| POST | `/api/pressure-pitch` | 圧迫ピッチモードの質問生成・スコアリング |
| POST | `/api/speakable-english` | 英語モード時の発音ヒント生成（オプション） |
| GET | `/api/sessions/{id}` | 反復練習用に過去原稿を再ロード |
| PUT | `/api/sessions/{id}` | 練習結果（イテレーション）を保存 |

## 13. 状態 / 保存内容

| state | 内容 |
|---|---|
| `state.iteration` | 現在のイテレーション番号（次回練習で+1） |
| `state.tpMode` | テレプロンプターモードのON/OFF |
| `state.tpSpeed` | スクロール速度 |
| `state.tpFontSize` | テレプロンプターのフォントサイズ |
| `state.voiceFollow` | 声追従ON/OFF |
| `state.pressureChat[]` | 圧迫ピッチモードの会話履歴 |
