# 設計資料_作業画面_ステップ1_スライド設定

> 対象: 作業画面 ステップ① 「スライドをセットする」
> HTML: `static/index.html` L93〜L271（左: スライドパネル / 右: `#content-1`）
> 主な関連JS関数: `handleSlideUpload()` / `processSlideFile()` / `applyPreset()` / `selectTargetType()` / `setLanguageMode()` / `saveStep1AndProceed()` / `goToStep()`

---

## 1. 画面概要

```
┌─ 左パネル (.slide-panel) ──────┬─ 右パネル (#content-1) ────────────┐
│ パネルヘッダー（タイトル+ナビ） │ <h2>① スライドをセットする</h2>     │
│ ┌─ #slide-viewer ───────────┐ │ ▸ ②録音→ ボタン                    │
│ │ #upload-area              │ │ ─────────────────────────────────  │
```

## 2. 左パネル: スライドビューアー

### 2-1. パネルヘッダー (`.panel-header`)

| 要素 | ID | 種別 | 内容 / 動作 |
|---|---|---|---|
| パネルタイトル | `#slide-panel-title` | テキスト | 既定値 `スライド` |
| PowerPoint並列起動ボタン | `#btn-open-pptx` | ボタン (`btn btn-sm btn-pptx`) | `📊 PowerPointで開く` / `openPptx()` を呼ぶ。**PPTXアップロード時のみ表示**。`POST /api/open-pptx` でPC上のPowerPointを起動 |
| 前のスライドボタン | `#btn-prev` | ボタン (`btn btn-icon`) | `◀` / `prevSlide()`、先頭/未アップロード時は `disabled` |
| ページカウンタ | `#slide-counter` | テキスト | `現在 / 総数` （未アップロード時は `－`） |
| 次のスライドボタン | `#btn-next` | ボタン (`btn btn-icon`) | `▶` / `nextSlide()`、末尾/未アップロード時は `disabled` |

### 2-2. PowerPoint並列起動バナー (`#pptx-parallel-banner`)

PowerPoint起動後に表示される情報バナー（ステップ1〜2で利用）。

| 要素 | 種別 | 内容 / 動作 |
|---|---|---|
| `.ppb-icon` `📊` | アイコン | 装飾 |
| `.ppb-title` | テキスト | `PowerPoint 並列起動中` |
| `.ppb-sub` | テキスト | 使い方ガイド |
| `.ppb-tip` | テキスト | `💡 スライドを切り替えたら → を押して同期` |
| `.ppb-close` ✕ | ボタン | `closePptxBanner()` でバナーを閉じる |

### 2-3. アップロードエリア (`#upload-area`)

ファイル未アップロード時のみ表示。ドラッグ&ドロップ受付。

| 要素 | 種別 | 内容 / 動作 |
|---|---|---|
| `.upload-icon` 📎 | アイコン | 装飾 |
| 説明文 `スライドをここにドロップ` | テキスト | 装飾 |
| `または` | テキスト | 装飾 |
| `<label for="slide-file-input">ファイルを選択` | ラベルボタン (`btn btn-secondary`) | クリックで `<input type="file">` を発火 |
| `#slide-file-input` | `<input type="file">` (display:none) | accept: `.pdf,.png,.jpg,.jpeg,.pptx,.ppt`。change で `handleSlideUpload(event)` |
| `.upload-hint` | テキスト | `PDF / PNG / JPG / PPTX 対応` |
| `.upload-skip > a` | リンク | `スライドなしで録音に進む →` / `goToStep(2)` |

ドラッグ中は `.drag-over` クラスが付与されハイライト。ドロップで `processSlideFile()` を呼び `POST /api/upload-slides` にアップロード。

### 2-4. スライドプレビュー / 変換中表示

| 要素 | 種別 | 役割 |

| ┗ `.spinner` | スピナー | くるくる |
| ┗ `#slide-converting-label` | テキスト | `変換中...` / PPTX時は `PowerPoint変換中...` |

### 2-5. 練習モード時の原稿パネル（ステップ1では非表示）

`#practice-script-panel`（ステップ5でのみ表示）。本ステップでは `display:none`。

## 3. 右パネル: ステップ1コンテンツ (`#content-1`)

### 3-1. ステップヘッダー (`.step-header`)

| 要素 | 種別 | 内容 |
|---|---|---|
| `<h2>` | 見出し | `① スライドをセットする` |
| 説明文 `<p>` | テキスト | アップロード手順案内 |
| `.step-nav-btn.next` | ボタン | `②録音 →` / `goToStep(2)` |

### 3-2. セッション名入力

| 要素 | ID | 種別 | 内容 / 動作 |
|---|---|---|---|
| ラベル | — | `<label>` | `セッション名` |
| 入力欄 | `#session-title` | `<input type="text">` (`input-field`) | プレースホルダ「例：製品紹介プレゼン、自己紹介LT など」。空欄で保存時は `セッション {現在日時}` で自動命名 |

### 3-3. ⚡ クイックスタート（プリセット）

5種類のプリセットボタン（`.preset-grid > .preset-btn`）。クリックすると `applyPreset(key)` が呼ばれ、目的タイプ・目標時間・ヒントが自動セットされる。

| `data-preset` | アイコン | 名前 | 説明 | 概要 |
|---|---|---|---|---|
| `vc` | 💰 | VCピッチ | 5分・投資家向け | targetType=vc, 目標5分 |
| `ringi` | 🏢 | 社内稟議 | 10分・役員向け | targetType=ringi, 目標10分 |
| `academic` | 🎓 | 学会発表 | 15分・研究者向け | targetType=academic, 目標15分 |
| `interview` | 👔 | 面接対策 | 3分・面接官向け | targetType=interview, 目標3分 |
| `lt` | ⚡ | LT発表 | 5分・コミュニティ向け | targetType=general, 目標5分 |

| 要素 | ID | 種別 | 内容 / 動作 |
|---|---|---|---|
| プリセットヒント | `#preset-hint` | テキスト (display:none → block) | 選択後 `💡 {ラベル}モード: {hint}` を表示 |

選択中のプリセットは `.preset-btn.active` でハイライト表示されます。

### 3-4. 🎯 発表の目的・想定聴衆 (`#target-type-grid`)

5種類のターゲットボタン (`.target-btn`)。クリックで `selectTargetType(this)`。`data-type` をもとに `state.targetType` を更新し、AI改善のトーンに反映。

| `data-type` | アイコン | 表示 |
|---|---|---|
| `general`（既定で `.active`） | 📢 | 一般プレゼン |
| `vc` | 💰 | VCピッチ |
| `ringi` | 🏢 | 社内稟議 |
| `academic` | 🎓 | 学会発表 |
| `interview` | 👔 | 面接対策 |

### 3-5. ⏱ 目標発表時間 (`.duration-row`)

| 要素 | ID | 種別 | 内容 / 動作 |
|---|---|---|---|
| 分入力 | `#target-minutes` | `<input type="number">` (`input-field duration-input`) | min:0 / max:60 / 既定:0 |
| `分` | `.duration-label` | テキスト | 装飾 |
| 秒入力 | `#target-seconds` | `<input type="number">` (`input-field duration-input`) | min:0 / max:59 / 既定:0 |
| `秒（0のとき制限なし）` | `.duration-label` | テキスト | 補足説明 |

入力値は `saveStep1AndProceed()` 内で `state.targetDuration` に秒単位で保存。

### 3-6. 🌐 プレゼン言語 (`#lang-mode-grid`)

| `data-lang` | 表示 | 動作 |
|---|---|---|
| `ja`（既定で `.active`） | 🇯🇵 日本語 | `setLanguageMode('ja')` |
| `en` | 🇺🇸 英語プレゼンに変更 / 「文字おこし後に英語へ翻訳」 | `setLanguageMode('en')` |

英語選択時はステップ3で `#translate-section` が表示され、英訳ボタンが出現。

### 3-7. 補足カード

| 要素 | 種別 | 内容 |
|---|---|---|
| `.info-card` | 装飾カード | `💡 スライドなしでもOKです。テキストや考えをまとめる目的でも使えます。` |

### 3-8. アクション (`.step-actions`)

| 要素 | 種別 | 内容 / 動作 |
|---|---|---|
| `[録音に進む →]` | ボタン (`btn btn-primary`) | `saveStep1AndProceed()`。セッション名・目的タイプ・目標時間を `PUT /api/sessions/{id}` で保存し、`goToStep(2)` |

## 4. 状態 / 保存内容

| 項目 | 保存先 | キー |
|---|---|---|
| セッションタイトル | サーバー / `state.session` | `title` |
| 目的タイプ | サーバー / `state.targetType` | `target_type` |
| 目標時間 | サーバー / `state.targetDuration`（秒） | `target_duration` |
| プレゼン言語 | `state.presentationLang` | フロント保持。ステップ3の翻訳UIに影響 |
| アップロード済みスライド | `state.slides`（PNG URL配列） | サーバーで永続化 |
| PPTX元ファイル | `state.pptxOriginalFile` / `state.hasPptxSource` | PowerPoint並列起動ボタン用 |

---

## 5. 関連API

| メソッド | エンドポイント | 用途 |
|---|---|---|
| POST | `/api/upload-slides` | スライド（PDF/PNG/JPG/PPTX）アップロード→PNG変換 |
| POST | `/api/convert-pdf` | PDF→画像変換（補助） |
| POST | `/api/open-pptx` | サーバーOSでPPTXファイルをPowerPointで開く |
| GET | `/api/slides/{filename}` | 変換済みスライド画像取得 |
| PUT | `/api/sessions/{id}` | ステップ1の入力をセッションに保存 |

---

## 6. 主要遷移

| トリガー | 遷移 |
|---|---|
| ファイルドロップ / ファイル選択 | スライド変換→ビューア表示。完了後そのまま同画面に留まる |
| `スライドなしで録音に進む →` | `goToStep(2)` |
| `[録音に進む →]` | `saveStep1AndProceed()` → `goToStep(2)` |
| プリセットクリック | 目的タイプ・時間が自動入力されるのみ（画面遷移なし） |
