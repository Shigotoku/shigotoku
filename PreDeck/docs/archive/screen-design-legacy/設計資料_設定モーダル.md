## 1. 画面概要

ヘッダーの `⚙️ 設定` から開かれるモーダル。`.modal-overlay` 上の `.modal-box.modal-box-wide` に「設定タブ」と「セットアップガイドタブ」の2タブを内包しています。

```
┌─ #modal-settings (.modal-overlay) ──────────────────────────────┐
│  .modal-box.modal-box-wide                                       │
│  ┌─ .modal-header ──────────────────────────────────────────┐   │
│  │ ⚙️ 設定                                          [✕]      │   │
│  └────────────────────────────────────────────────────────────┘   │
│  .settings-tabs : [⚙️ 設定] [🚀 セットアップガイド]                │
│  ┌─ #spanel-settings (タブ1: 設定) ────────────────────────┐    │
│  │ 🎙️ 文字起こし設定 (方法/言語/Whisperモデル)               │    │
│  │ 🤖 AI スクリプト改善設定 (OpenAI / Ollama)                 │    │
│  └──────────────────────────────────────────────────────────┘    │
│  ┌─ #spanel-setup (タブ2: セットアップガイド) ────────────┐     │
│  │ STEP1: 文字起こし（local/webspeech/api）                  │    │
│  │ STEP2: AI原稿改善（ollama/openai）                        │    │
│  │ STEP3: 動作テスト（マイク/文字起こし/AI）                   │    │
│  └──────────────────────────────────────────────────────────┘    │
│  .modal-footer                                                   │
│  [💾 設定を保存] [🔍 全項目を一括確認]（条件付き）                │
└──────────────────────────────────────────────────────────────────┘
```

## 3. タブ① 設定 (`#spanel-settings`)

#### 3-2-c. PCスペック / ローカルLLM 提案 (`.pc-spec-panel`)

| 要素 | ID | 動作 |
|---|---|---|
| `[PCスペックを確認して提案を表示]` | ボタン | `refreshSystemSpecRecommendations()` → 設定タブの `#pc-spec-summary` / `#llm-recommend-body` と、セットアップ STEP2 の `#pc-spec-summary-setup` / `#llm-recommend-body-setup` を同内容で更新 |
| スペック要約 | `#pc-spec-summary`（設定） / `#pc-spec-summary-setup`（ガイド） | OS・RAM・CPU論理数・GPU 要約・PCクラス |
| 提案カード | `#llm-recommend-body` / `#llm-recommend-body-setup` | 推奨モデル・`ollama pull` 行（コピー）・`applyRecommendedOllamaModel()` |

#### メソッド切替タブ (`.setup-method-tabs`)

#### 4-1-a. ローカルWhisper (`#setup-local`)

## 6. QRコードモーダル (`#qr-modal`)

ステップ4の `[💾 保存 ▾]` → `[📱 QRコードで携帯に転送]`（`showQRCode()`）から開く。

| 要素 | ID | 種別 | 内容 / 動作 |
|---|---|---|---|
| ヘッダー | `.modal-header` | コンテナ | `📱 携帯で原稿を確認` |
| `[✕]` | `.modal-close` | ボタン | `closeQRModal()` |
| 案内文 | `.qr-instruction` | テキスト | `同じWi-Fiに接続した状態で、スマートフォンのカメラでQRコードを読み取ってください。` |
| QR表示 | `#qr-code-container.qr-code-container` | コンテナ | qrcode.js が描画 |
| URL表示 | `#qr-url-display.qr-url-display` | テキスト | 生成された `http://{LAN_IP}:{port}/...` |
| 注意書き | `.qr-note` | テキスト | `※ アプリと同じネットワーク内でのみアクセスできます` |
| オーバーレイクリック | `#qr-modal` | — | 外側クリックで `closeQRModal()` |

外部CDN: `cdnjs.cloudflare.com/ajax/libs/qrcodejs/1.0.0/qrcode.min.js`

`GET /api/local-ip` でローカルIPを取得し、原稿閲覧用URLを生成します。
