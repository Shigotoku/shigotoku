# 設計資料_作業画面_ステップ3_文字おこし

> 対象: 作業画面 ステップ③ 「文字おこし確認」
> HTML: `static/index.html` L355〜L499（右: `#content-3`）
> 主な関連JS関数: `proceedToTranscribe()` / `discardFromStep3()` / `requestTranslation()` / `setTranslationStyle()` / `toggleAnalysisPanel()` / `runFillerAnalysis()` / `runStructureAnalysis()` / `runStumbleAnalysis()` / `runMetaphorAnalysis()` / `runEnergyAnalysis()` / `runSpeechAnalysis()`

---

## 1. 画面概要

Whisper / Web Speech APIで生成された文字おこしを確認・編集し、各種解析（フィラー、弱気ワード、話速、構造、つまずき、比喩、熱量）を任意で実行する画面。英語プレゼンモード時は翻訳セクションも表示されます。

```
┌─ 左: スライドパネル ─┬─ 右: #content-3 ────────────────────────────┐
│ （ステップ1と同じ）  │ <h2>③ 文字おこし確認</h2>                    │
│                    │ ▸ ←②録音 / ④原稿改善→                        │
│                    │ #step3-discard-area                         │
│                    │   🗑️ 録音を削除して録り直す                  │
│                    │ #transcribe-status (Whisper処理中スピナー)   │
│                    │ #translate-section (英語モード時のみ)         │
│                    │ ┌── #transcript-area ────────────────────┐ │
│                    │ │ #transcript-meta（時間・文字数など）     │ │
│                    │ │ #transcript-editable (contenteditable)  │ │
│                    │ │ #analysis-btn-bar (7つの分析ボタン)      │ │
│                    │ │ ── 各 .analysis-panel（クリックで開閉）── │ │
│                    │ │   フィラー / 弱気 / WPM / 構造 /         │ │
│                    │ │   つまずき / 比喩 / 熱量                  │ │
│                    │ └────────────────────────────────────────┘ │
└────────────────────┴────────────────────────────────────────────┘
```

## 5. 英語翻訳セクション (`#translate-section`)

ステップ1で「英語プレゼンに変更」を選んだ場合のみ表示（`state.presentationLang === 'en'`）。

### 5-1. ヘッダー

| 要素 | 種別 | 内容 |
|---|---|---|
| `.translate-section-header` | コンテナ | `🌐 英語に翻訳` |
| `.translate-section-hint` | テキスト | `翻訳後に原稿改善画面へ進みます` |

### 5-2. 翻訳スタイル選択 (`#translate-style-btns`)

クリックで `setTranslationStyle(style)`。`state.translationStyle` を更新。

| `data-style` | ラベル | 用途 |
|---|---|---|
| `formal`（既定で `.active`） | フォーマル | ビジネス標準 |
| `casual` | 砕けた言い方 | カジュアルピッチ |
| `academic` | 学会用語 | 学術発表 |
| `accented` | 個性あり | キャラのある英語 |

### 5-3. 翻訳実行

| 要素 | 種別 | 内容 / 動作 |
|---|---|---|
| `[🌐 英語に翻訳して原稿改善へ →]` | ボタン (`btn btn-primary`) | `requestTranslation()` → `POST /api/translate-transcript`、結果を文字おこし欄に反映後、ステップ4へ自動遷移 |
| `#translate-status` | コンテナ (display:none → flex) | スピナー + `翻訳中...` |

## 6. 文字おこし表示・編集 (`#transcript-area`)

### 6-1. メタ情報 (`#transcript-meta`)

`runSpeechAnalysis()` などにより動的に挿入。録音時間・総文字数・推定話速などを表示。

### 6-2. 編集可能エディタ (`#transcript-editable`)

| 属性 | 値 |
|---|---|
| `contenteditable` | `true` |
| `data-placeholder` | `文字起こし結果がここに表示されます（直接編集もできます）...` |

文字おこし完了後、本文がプレーンテキストとして注入され、自由に編集できます。

### 6-3. 分析ボタンバー (`#analysis-btn-bar`)

`hasRecording` が真のときのみ表示。各ボタンは対応する `.analysis-panel` をトグル開閉します。

| ID | アイコン | ラベル | 対応パネル | 主な動作 |
|---|---|---|---|---|
| `#abtn-filler` | 🚫 | フィラー | `#filler-analysis` | `toggleAnalysisPanel('filler')` 初回展開時 `runFillerAnalysis()` |
| `#abtn-weak` | 💪 | 弱気ワード | `#weak-word-analysis` | `toggleAnalysisPanel('weak')` |
| `#abtn-wpm` | ⚡ | 話速 | `#wpm-analysis` | `toggleAnalysisPanel('wpm')` |
| `#abtn-structure` | 🏗️ | 構造 | `#structure-analysis` | `toggleAnalysisPanel('structure')` 初回展開時 `runStructureAnalysis()` |
| `#abtn-stumble` | 🔍 | つまずき | `#stumble-analysis` | `toggleAnalysisPanel('stumble')` 初回展開時 `runStumbleAnalysis()` |
| `#abtn-metaphor` | 💡 | 比喩 | `#metaphor-suggestions` | `toggleAnalysisPanel('metaphor')` 初回展開時 `runMetaphorAnalysis()` |
| `#abtn-energy` | 🌡️ | 熱量 | `#energy-heatmap` | `toggleAnalysisPanel('energy')` 初回展開時 `runEnergyAnalysis()` |

## 7. 各分析パネル

各パネルは `.analysis-panel` クラス + 個別ID + 個別CSS。ヘッダーに「再解析」ボタン（多くのパネル）と「✕ 閉じる」ボタンを持ちます。

### 7-1. フィラー解析 (`#filler-analysis`)

| 要素 | 種別 | 内容 / 動作 |
|---|---|---|
| ヘッダーラベル | テキスト | `🚫 フィラー（不要な言葉）検出` |
| `[再解析]` | ボタン (`btn btn-sm btn-ghost`) | `runFillerAnalysis()` を強制再実行 |
| `[✕]` | ボタン (`.analysis-panel-close`) | パネルを閉じる |
| `#filler-result.filler-result` | 表示エリア | 検出されたフィラー語と件数、ハイライト |

API: `POST /api/analyze-fillers`

### 7-2. 弱気ワード検出 (`#weak-word-analysis`)

| 要素 | 種別 | 内容 |
|---|---|---|
| ラベル | テキスト | `💪 弱気ワード検出` |
| `.weak-hint` | テキスト | `AIの原稿改善で自動修正されます` |
| `[✕]` | ボタン | `toggleAnalysisPanel('weak')` |
| `#weak-word-result.weak-result` | 表示エリア | 弱気ワードのリスト・件数 |

クライアント側ルールベース判定（API呼び出しなし）。

### 7-3. タイミング内訳 (`#timing-breakdown`)

スライドごとの発話時間など。`runSpeechAnalysis()` で生成。

### 7-4. WPM（話速）分析 (`#wpm-analysis`)

| 要素 | ID | 種別 | 内容 |
|---|---|---|---|
| ラベル | — | テキスト | `⚡ 話速（文字数/分）` |

## 8. 関連API

## 9. 状態 / 保存内容

| state | 内容 |
|---|---|
| `state.previousTranscript` | 編集前の文字おこし原文（差分計算で使用） |
| `state.transcriptBySlide` | スライド別の発話テキスト辞書 |
| `state.translationStyle` | 翻訳スタイル（`formal` / `casual` / `academic` / `accented`） |

オートセーブ: 文字おこしテキストは編集後 `_autoSaveTranscript()` で `PUT /api/sessions/{id}` に保存。
