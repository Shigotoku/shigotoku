# 設計資料_全体構成

> 対象: PreDeck フロントエンド (`static/index.html` + `static/app.js` + `static/style.css`)
> 最終確認日: 2026年5月

---

## 1. アプリ全体のレイアウト

```
┌─────────────────────────────────────────────────────────────┐
│  [app-header] ヘッダー（常時表示）                           │
│  ┌─────────────────┐                  ┌────────┬────────┐   │
│  │ ロゴ + アプリ名  │                  │🏠 ホーム │⚙️ 設定 │   │
│  └─────────────────┘                  └────────┴────────┘   │
├─────────────────────────────────────────────────────────────┤
│  [app-main] メインコンテンツ（画面切替）                     │
│   ├─ #screen-home  : ホーム画面                              │
│   └─ #screen-work  : 作業画面（ステップ1〜5）                │
└─────────────────────────────────────────────────────────────┘

[modal-settings]   設定モーダル（オーバーレイ）
[qr-modal]         QRコードモーダル（オーバーレイ）
[toast]            トースト通知（右下フローティング）
```

ルートDOMは `#app` ひとつだけで、その中で `screen` クラスを持つ複数のコンテナを `display:none/block` で切り替える SPA 構成です。

---

## 2. 共通ヘッダー (`<header class="app-header">`)

| ID / セレクタ | 種別 | 表示内容 | 動作 |
|---|---|---|---|
| `.header-left .app-logo-img` | 画像 | `/static/logo.png` | 装飾のみ |
| `.header-left .app-title` | テキスト | `プレデキ (PreDeck)` | 装飾のみ |
| `#btn-home` | ボタン (`btn btn-ghost`) | `🏠 ホーム` | `showHome()` を呼び、ホーム画面に戻る |
| ヘッダー右の設定ボタン | ボタン (`btn btn-ghost`) | `⚙️ 設定` | `showSettings()` を呼び、設定モーダルを開く |

ヘッダーはどの画面・どのステップでも常に表示されます。

---

## 3. メインコンテンツの画面切替

| 画面ID | ラベル | 役割 | 主な遷移元 |
|---|---|---|---|
| `#screen-home` | ホーム画面 | 新規セッション作成・既存セッション一覧 | アプリ起動時／ヘッダー🏠 |
| `#screen-work` | 作業画面 | スライド→録音→文字おこし→原稿改善→練習の5ステップ | ホーム画面の「✨ 新しいセッションを開始」／既存セッション選択 |

`screen` クラスに `active` を付け外しして表示制御。`showHome()` で `#screen-home` を、`createNewSession()` / セッション選択で `#screen-work` をアクティブにします。

---

## 4. 作業画面の5ステップ構造

`#screen-work` は次の3要素から構成されています。

### 4-1. ステップインジケーター (`.step-bar`)

横並びの5つの円形ステップで、`onclick="goToStep(n)"` により任意ステップへジャンプできます。

| ID | ステップ | ラベル | 関連コンテンツID |
|---|---|---|---|
| `#step-dot-1` | ① | スライド | `#content-1` |
| `#step-dot-2` | ② | 録音 | `#content-2` |
| `#step-dot-3` | ③ | 文字おこし | `#content-3` |
| `#step-dot-4` | ④ | 原稿改善 | `#content-4` |
| `#step-dot-5` | ⑤ | 練習 | `#content-5` |

- アクティブステップは `.active` クラスで強調。
- 各ステップ間は `.step-line` で接続。

### 4-2. 左パネル: スライドビューアー (`.slide-panel`)

ステップを跨いで常に表示される共通ビューア。詳細は各ステップの設計資料および `設計資料_作業画面_ステップ1_スライド設定.md` を参照。

主要要素:
- `#slide-panel-title` パネルタイトル
- `#btn-open-pptx` PowerPoint並列起動ボタン（PPTX時のみ表示）
- `#btn-prev` / `#btn-next` / `#slide-counter` スライドナビ
- `#pptx-parallel-banner` PowerPoint並列起動中バナー
- `#upload-area` 初期アップロードエリア
- `#slide-image` スライドプレビュー画像
- `#slide-converting` 変換中スピナー
- `#practice-script-panel` 練習モード時の原稿表示

### 4-3. 右パネル: ステップコンテンツ (`.content-panel`)

`#content-1` 〜 `#content-5` のうち、現在のステップだけを `display:block` 表示。

各ステップ共通の構造:
```
<div class="step-content" id="content-N">
  <div class="step-header">
    <h2>... タイトル</h2>
    <div class="step-nav-btns">
      <button class="step-nav-btn prev">← 前のステップ</button>
      <button class="step-nav-btn next">次のステップ →</button>
    </div>
  </div>
  ... 各ステップの本文 ...
</div>
```

## 5. 共通の補助UI

### 5-1. トースト通知 (`#toast`)

右下に表示される短いメッセージ。成功・警告・エラーをアプリ全体で統一表示。`style="display:none"` を切り替えて出現。

### 5-2. キーボードショートカット表示 (`.kbd-help-bar` 等)

- ステップ2 / ステップ5: `← →` でスライド切替、`Space` で録音開始/停止のヒントを表示。

### 5-3. ローディング・スピナー

`<div class="spinner"></div>` を以下の各所で再利用:
- `#slide-converting` PDF / PPTX 変換中
- `#transcribe-status` Whisper / API による文字起こし中
- `#improve-status` AI原稿改善中
- `#translate-status` 英語翻訳中

## 7. 主要な画面遷移フロー

```
[ホーム画面]
   │
   ├─ ✨ 新しいセッションを開始 → createNewSession()
   │     ↓
   │  [作業画面 ステップ1: スライド設定] (#content-1)
   │     ↓ saveStep1AndProceed()
   │  [作業画面 ステップ2: 録音]        (#content-2)
   │     ↓ proceedToTranscribe()
   │  [作業画面 ステップ3: 文字おこし]  (#content-3)
   │     ↓ goToStep(4)
   │  [作業画面 ステップ4: 原稿改善]    (#content-4)
   │     ↓ goToStep(5)
   │  [作業画面 ステップ5: 練習モード]  (#content-5)
   │     ├─ startNextIteration() → ステップ2へ戻り反復
   │     └─ finishSession()      → ホーム画面へ
   │
   └─ 既存セッション選択（リスト項目クリック）
         ↓
       保存ステップに応じて該当ステップを復元表示
```

ステップ間は `.step-nav-btns` のボタンや `goToStep(n)` のクリックでも自由に行き来できますが、データの有無により一部UIが切り替わります（例: 録音データがないと文字おこしは空表示）。
