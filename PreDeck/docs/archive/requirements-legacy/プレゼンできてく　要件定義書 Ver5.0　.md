# **プレゼン原稿 反復生成・突破アプリ 要件定義書 Ver 5.0（完全統合版）**

## **1\. プロダクトの再定義とビジョン**

* **本質:** 本プロダクトは単なる「スピーチ練習アプリ」ではない 。目的は「上手に話すこと」ではなく「通すこと」に特化した、\*\*「意思決定突破ツール（Decision Breakthrough Engine）」\*\*である 。  
  \+1  
* **戦略的差別化:** 既存のスピーチコーチ、発音アプリ、翻訳アプリとは一線を画し、「意思決定突破 × 英語適応 × 即応耐性 × 成長可視化」を統合した市場に存在しないポジションを確立する 。

## **2\. ターゲット戦略とユーザージャーニー**

* **最初の勝ちパターン（GTM戦略）:** 第1ターゲットは「VCピッチ × 起業家コミュニティ」 。強い課題感（資金調達）、短時間勝負、圧迫質問の存在、SNS拡散性から、ここで熱狂的なファンを作りブランドを立てる 。  
  \+1  
* **進化モデル（ユーザージャーニー）:** 「A層（プレゼン練習）」から入り、自然に「B層（英語プレゼン突破）」へとユーザーを引き上げる設計とする 。  
  \+2  
  * **Stage 1 (話せる):** フィラー除去、ペース可視化、構造診断  
  * **Stage 2 (通せる):** 勝率スコア、圧迫モード、想定質問生成  
  * **Stage 3 (英語で戦える):** 日本語→英語変換、Speakable English、発音トレーニング、文化適応解析  
     \+1

## **3\. システムアーキテクチャと提供形態**

* **多層構造と提供形態:** 無料のChrome拡張を入口（集客）とし、高度なローカルアプリへ誘導するファネル戦略 。  
  \+3  
  * 1️⃣ Chrome拡張（無料導線：Google Slides連動）  
     \+3  
  * 2️⃣ ローカルアプリ（Electron/Tauri：全ファイル対応）  
     \+2  
* **AIコスト最小化・プライバシー設計:**  
  * 文字起こしはWeb Speech API / OS標準機能でローカル処理（無料化） 。  
    \+1  
  * AI処理はBYOK（ユーザーのAPIキー持ち込み）やローカルLLMを優先し、運営のサーバー代を抑える 。  
    \+2  
  * カメラやログ保存は明示的な同意制・ON/OFF設定とする 。

## **4\. コア機能群（モジュール構造・完全統合）**

すべての高度機能はモジュール化され、ユーザーがON/OFFやプリセット適用を自由に行える 。

### **🧠 Aレイヤー：プレゼン突破エンジン（日本語ベース）**

* 4-1. 原稿彫刻エンジン: フィラー除去、全体時間の最適化、差分ハイライト表示、業界特化トーン（VC/稟議/アカデミア等）への変換 。  
  \+1  
* 4-2. 構造診断: ストーリーアーク解析、WHYの強度、問題提起の明確さ、根拠密度、競合比較の網羅性をチェック 。  
  \+1  
* 4-3. 勝率スコア (Pitch Score Engine): 想定対象（VC、稟議、学会等）を選択すると、通過確率スコアと弱点優先順位を出力 。  
  \+1  
* 4-4. 話し方・パフォーマンス解析: 弱気ワードの検出と言い切り提案、WPM（ペース）グラフ、声の抑揚による「熱量ヒートマップ」、棒読み検知 。カメラによる視線・表情解析 、つまずき検知からの「比喩・メタファー自動提案」 。  
  \+4  
* 4-5. 圧迫ピッチモード: プレゼン中にAI音声でランダムに割り込み質問（ヤジ）を行い、即応力と再開のスムーズさを採点 。  
  \+1

### **🌍 Bレイヤー：英語プレゼン突破エンジン**

* 5-1. 用途別英語変換: 日本語の音声を、単なる翻訳ではなく「文化文脈補正」を含めたVC英語やアカデミック英語に変換 。  
  \+1  
* 5-2. Speakable English & 発音: 初心者向けに文を分割し、呼吸ポイントや強調語をハイライト 。単語〜通し練習の3段階発音トレーニング、シャドーイングモード 。  
  \+2  
* 5-3. 単語帳 & 崩し言い換え: クリックで単語登録・忘却曲線による復習 。フォーマル⇄カジュアルのトーン切替 。  
  \+2  
* 5-4. 英語即応＆文化適応: 英語での圧迫質問対応 。英語圏特有の「主張の弱さ」「自己主張不足」を指摘する文化適応解析 。  
  \+2

### **🛠 共通サポート機能**

* **スマート・プロンプター:** 音声に追従するハイライト、読み飛ばしにも対応する文脈同期 。  
* **成長可視化レイヤー:** スコア推移、日本語→英語移行率、自信曲線のグラフ化による継続率向上 。  
  \+2  
* **プリセットモード:** ワンクリックで「VCピッチ」「本番前（邪魔しない）」など最適なモジュール構成に切り替え 。  
  \+1

# **💡 さらなる改善点・追加機能のご提案**

Ver 4.0までの要件定義は「個人がプレゼンを突破するための究極の武器」として完璧です。ここから**さらにビジネスをスケールさせる（特にEnterprise版で単価を上げる）ため**、以下の視点を追加することを提案します。

### **提案1：共有と「非同期フィードバック」機能（バイラルループの強化）**

現在の要件は「AIとの孤独な戦い」に特化していますが、実際のVCピッチや稟議の前には、必ずメンターや上司に見てもらいます。

* **追加機能:** 練習の録画・録音データと、AIによる「勝率スコア・構造診断結果」をセットにして、**専用のURLで他人に共有できる機能**。  
* **効果:** 共有された側（メンターや上司）は、ブラウザ上で動画を見ながらタイムラインにコメントを残せます。このURL共有が、アプリの強力な口コミ・拡散（バイラルループ）を生み出します。

### **提案2：チームの「勝ちパターン」学習機能（Enterprise向けキラー機能）**

* **追加機能:** 社内の「過去に稟議を通した優秀なプレゼン」や「資金調達に成功したピッチ」のデータをアプリにアップロードすることで、**AIが「その企業特有の勝ちパターン（好まれる言葉選びや構成）」を学習する機能**。  
* **効果:** 汎用的なスコアではなく、「自社の社長が好むフォーマットに合っているか」を判定できるようになります。これにより、法人契約（BtoB）の単価を一気に引き上げることが可能です。

### **提案3：「本番」のリアルタイム・アシスト（デスクトップアプリの強み）**

「練習」だけでなく「本番」もサポート領域に含めます。

* **追加機能:** ZoomやTeamsでのオンライン本番プレゼン中、画面の端に透明なウィジェットとして常駐。**「いま少し早口になっています」「相手がしかめっ面です（相手の表情解析）」といったアラートをリアルタイムでプレゼンターだけに見せる機能**。  
* **効果:** 「練習から本番まで、これさえ起動しておけば絶対に事故らないお守り」として、ユーザーの解約率（チャーンレート）を極限まで下げることができます。
