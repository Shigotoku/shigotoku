# **プレゼン原稿 反復生成・練習アプリ 要件定義書（Ver 2.0）**

## **1\. プロジェクト概要**

* **目的:** 「とりあえず話す→AIと磨き上げる」の反復プロセスを通じ、自然で完成度の高いプレゼンを構築する。  
* **ターゲット:** プレゼンやピッチを控えるビジネスパーソン、起業家、研究者。  
* **ビジネスモデル（2段階ファネル戦略）:**  
  1. **集客（リード獲得）:** Google Slides専用の「無料Chrome拡張機能」でバイラル展開。  
  2. **収益化（コア機能）:** PCにインストールする「ローカルアプリ（月額課金制）」への誘導。

## **2\. システムアーキテクチャ**

* **フロントエンド・アプリ基盤:** \* 拡張機能: HTML/JS \+ Chrome Extension API  
  * ローカルアプリ: Electron または Tauri (Mac/Windows両対応)  
* **AI・音声処理（コスト最小化の仕組み）:**  
  * **BYOK（APIキー持ち込み）:** ユーザー自身が契約するOpenAI/GeminiのAPIキーを入力させることで、運営側のAIサーバー代をゼロにする。  
  * **Web Speech API / OS標準音声認識:** 文字起こしはクラウドに送らず、ブラウザやOSの標準機能（ローカル）で行い無料化。  
* **認証・決済:** Stripe決済と連動したクラウド上のライセンス認証システム。

---

## **3\. 機能要件（提供形態別の切り分け）**

### **3.1 【フェーズ1】Chrome拡張機能（無料・集客用）**

* **Google Slides連動サイドバー:** スライドの横に常駐。  
* **基本の文字起こし＆フィラー除去:** 喋った内容から「あー」「えー」を消してテキスト化。  
* **1スライド限定のAI修正:** お試しとして、現在表示している1枚のスライド分だけ原稿を整える。

### **3.2 【フェーズ2】ローカルデスクトップアプリ（有料・月額課金）**

* **全ファイル形式対応:** PowerPoint (PPTX), Keynote, PDFの直接読み込み。  
* **無制限の通し練習＆全体最適化:** プレゼン全体の時間を計測し、指定時間（例：5分）に収まるよう全体の文字数を自動調整。  
* **差分ハイライト＆業界特化トーン:** AIの修正箇所の可視化と、「IT」「金融」「アカデミア」などの専門用語への言い換え提案。

## **4\. 競合から取り入れるべき「すごい機能」（市場のベストプラクティス）**

既存のスピーチコーチAI（Yoodli, Poisedなど）で高く評価されている機能をローカルアプリに組み込みます。

* **👀 弱気ワード（Hedging words）の可視化:**  
  * 「〜だと思います」「たぶん」「〜な気がします」といった、自信のなさを表す言葉を検知し、赤線を引いて「言い切りましょう」と提案する機能。  
* **🐢 ペース・スピードメーター:**  
  * 1分間あたりの文字数（WPM）をグラフ化し、「3枚目のスライドで早口になっています。ここは重要なのでペースを落としましょう」と客観的に指摘する機能。  
* **📷 目線とジェスチャー解析（ローカルアプリ特権）:**  
  * PCのウェブカメラを使用し、原稿ばかり見ていないか（カメラ目線か）、手振りが使えているかをAIが画像認識で採点する機能。

## **5\. 【完全新規】市場にまだない、独自のキラー機能の提案**

他社がやっていない「原稿を彫刻のように作り上げる」というこのアプリのコンセプトだからこそ活きる、革新的な機能です。

#### **① 熱量（エナジー）マッピング機能**

* **概要:** 音声の「抑揚」と「声の大きさ」を波形データとして取得し、原稿テキストの上に色付け（ヒートマップ）します。  
* **効果:** ずっと同じトーン（棒読み）だと全体が青くなり、「ここは一番のフック（掴み）なので、声のトーンを上げて（赤色にして）もう一度練習しましょう」とAIが演出（演技）の指導までしてくれます。

#### **② 「つまずき検知」からのメタファー（比喩）自動生成**

* **概要:** ユーザーが練習中、何度も言葉に詰まったり、言い直したりしているスライド（＝本人も腑に落ちていない論点）をAIが自動検知します。  
* **効果:** 「この概念の説明に苦戦しているようですね。例えば『〇〇を車に例えると…』というような例え話（メタファー）を原稿に挿入しましょうか？」と、AIが構成のブレイクスルーを提案してくれます。

#### **③ 圧迫ピッチ（ヤジ・割り込み）モード**

* **概要:** Q\&Aシミュレーターの進化版です。ユーザーがプレゼンを**話している最中**に、突然PCからAI音声で「ちょっと待って、それって競合他社と何が違うの？」と割り込んで（ヤジを飛ばして）きます。  
* **効果:** 実際の経営会議やVCピッチで起こる「途中で遮られるストレス」への耐性を鍛えます。ユーザーが即興で切り返し、元のプレゼンにスムーズに戻れるかを採点します。

#### **④ スマート・プロンプター（音声追従スクロール）**

* **概要:** 完成した原稿を画面に表示し、ユーザーが「今、声に出して読んでいる場所」に合わせて、カラオケの字幕のように自動でハイライトとスクロールが進みます。  
* **効果:** ユーザーがアドリブで別の話を挟んだり、一部を読み飛ばしたりしても、AIが文脈を理解して「いまどこを話しているか」を見失わずに追従します。
