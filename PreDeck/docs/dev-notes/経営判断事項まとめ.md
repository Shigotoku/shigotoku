# PreDeck 販売化に向けた経営判断事項まとめ

作成日：2026-03-12

---

## 1. 利用形態・収益モデル

### 課題
- 無料・有料の機能をどう分けるか
- サブスク料金をどう設定するか

### 案

**フリーミアム型（推奨）**

| 機能 | 無料 | 有料（サブスク） |
|-----|------|--------------|
| 日本語録音・文字起こし（ローカルAI） | ✅ | ✅ |
| 日本語AIフィードバック | ✅ | ✅ |
| セッション保存・履歴 | ✅ | ✅ |
| 英語モード（録音・文字起こし） | — | ✅ |
| 英語AIフィードバック・スクリプト生成 | — | ✅ |
| 将来の高度分析機能 | — | ✅ |

**料金イメージ（要検討）**
- 月額：980円〜1,980円
- 年額：9,800円〜（月換算で割安感を出す）

---

## 2. 決済・サブスク管理

### 課題
- 決済・サブスク管理をどこに任せるか
- 開発コストと手数料のバランス

### 選択肢

| | **Gumroad**（推奨） | **Stripe** | **note** |
|--|------------|--------|------|
| 手数料 | 約10% | 約3.6%（＋実装コスト） | 約20% |
| 開発工数 | 少（ほぼゼロ） | 多（サーバー実装必要） | なし |
| ライセンスキー自動発行 | ✅ | 自前実装 | ❌ |
| 日本語対応 | △ | ✅ | ✅ |
| 向いているケース | 早期販売・小規模 | 本格運用・大規模 | コンテンツ販売 |

**推奨：まずGumroadで販売開始 → 軌道に乗ったらStripeへ移行**

---

## 3. ライセンス管理

### 課題
- 有料機能のコピー・不正利用をどう防ぐか
- サブスク期限切れをどう管理するか

### 選択肢

| | **Gumroad APIで認証**（推奨） | **自前サーバーで認証** |
|--|-------------|-------------|
| 開発コスト | 低（数十行の実装） | 高（サーバー構築・維持） |
| サーバー費用 | 不要 | 月額数千円〜 |
| 信頼性 | Gumroad依存 | 自前で制御可能 |
| 向いているケース | 初期・小規模 | 本格運用・大規模 |

---

## 4. OpenAI APIコスト負担

### 課題
- 英語AI機能はOpenAI APIを使う → 誰がAPIコストを払うか

### 選択肢

| | **ユーザーが自分のAPIキーを使う**（推奨） | **開発者側でAPIを提供** |
|--|---------------------|-------------|
| 開発者のAPIコスト | ゼロ | 利用量に応じて発生（赤字リスク） |
| ユーザーの手間 | OpenAIでAPIキー取得が必要 | なし（アプリだけで完結） |
| サーバー | 不要 | 必要 |
| 向いているケース | 初期・コスト重視 | UX重視・大規模 |

**推奨：当面はユーザー自身のAPIキーを使う方式で赤字リスクを排除**

---

## 5. 配布・インストール方法

### 課題
- ユーザーにどうアプリを届けるか
- インターネット環境がない場所でも使えるようにするか

### 選択肢

| | **ダウンローダー方式**（推奨） | **フルパッケージ同梱** |
|--|----------------|-------------|
| 配布ファイルサイズ | 約5MB | 約1GB |
| インストール時ネット | 必要（初回のみ） | 不要 |
| 配布方法 | Webダウンロード | USB・ファイル共有 |
| 向いているケース | Webサイト販売 | オフライン環境・法人一括 |

---

## 6. 判断が必要な事項一覧

| # | 判断事項 | 選択肢 | 推奨案 |
|---|---------|-------|-------|
| 1 | 有料機能の範囲 | 英語のみ / 他機能も有料化 | まず英語機能のみ |
| 2 | サブスク料金 | 月額・年額いくらにするか | 月額980〜1,980円（要検討） |
| 3 | 決済サービス | Gumroad / Stripe / note | Gumroadから開始 |
| 4 | APIコスト負担 | ユーザー負担 / 開発者負担 | ユーザー負担（OpenAI APIキー） |
| 5 | 配布方法 | ダウンロード / USB同梱 | ダウンロード |
| 6 | 販売開始時期 | いつ販売を始めるか | — |

---

## 参考：最小コスト構成での全体像

```
【ユーザーの流れ】
Gumroadで購入
    ↓
ライセンスキーをメールで受け取る
    ↓
アプリをWebサイトからダウンロード・install.bat実行
    ↓
アプリ内でライセンスキーとOpenAI APIキーを設定
    ↓
英語機能が使えるようになる

【開発者側のコスト】
・Gumroad手数料（売上の約10%）のみ
・サーバー費用：ゼロ
・OpenAI APIコスト：ゼロ
```
