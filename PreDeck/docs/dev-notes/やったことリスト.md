## 5. レガシー版を Strict Local Mode 既定に改修（M-001 / M-002）（2026-05-14）

- **背景：** Ver7.0 §1.2 で Strict Local Mode が既定ON必須、Web Speech API はローカルASR扱い禁止が確定。レガシー版が両方違反していたため、移行計画書 §9 の M-001・M-002（推奨案）を実施
- **対応：**
  - **M-001（Web Speech API 廃止）:**
    - `static/app.js` から `state.webSpeechRecog` / `webSpeechActive` を削除
    - `startRealtimeTranscript` / `stopRealtimeTranscript` 関数とその呼出箇所を削除（録音中のリアルタイム文字起こし）
    - `initWebSpeechUI` / `toggleWebSpeech` / `startWebSpeech` / `stopWebSpeech` / `checkWebSpeech` 関数を削除（文字おこし画面の補助入力）
    - `toggleVoiceFollow` / `startVoiceFollow` / `stopVoiceFollow` / `buildVoiceChunks` / `tryAdvancePosition` / `scrollTpToChunk` / `longestCommonSubstring` 関数を削除（テレプロンプター音声追従）
    - `selectSetupMethod` の選択肢から `'webspeech'` を削除
    - `static/index.html` から `realtime-transcript-area`・`tp-voice-btn`・transcribe方法プルダウンの `<option value="webspeech">`・セットアップガイドの `setup-webspeech` セクション・`smtab-webspeech` ボタンを削除
    - `static/style.css` から `.webspeech-area`・`.realtime-transcript-area`・`.rta-*`・`#tp-voice-btn` 関連スタイルを削除
    - 副次的に「文字起こし方法」のラベルを更新し、ローカルWhisper を「推奨」、OpenAI API を「クラウド・要同意」に明示
  - **M-002（クラウドAPI 既定OFF + 明示opt-in）:**
    - `cfg.aiMethod` 既定値を `'openai'` → `'ollama'` に変更（ローカル既定）
    - `cfg.cloudConsent`（boolean）と `cfg.cloudConsentAt`（同意日時 ISO8601）フィールドを追加
    - `requireCloudConsent(target, onDeclined, onApproved)` 関数を新設。未同意時はモーダル表示、同意済なら素通り
    - `openCloudConsentModal` / `approveCloudConsent` / `declineCloudConsent` / `revokeCloudConsent` を実装
    - 「☁️ クラウドAPIへの送信について（要同意）」モーダルを追加（送信先・送信データ・保存方針・課金・解除方法を表で開示）
    - `saveSettings` でクラウド選択時に未同意なら同意モーダルを呼び出し、同意拒否ならローカルに自動で戻す
    - `onTranscribeMethodChange` / `onAIMethodChange` でクラウド選択時に即座に同意モーダル
    - ヘッダー右上に `#strict-local-badge`（🔒 Strict Local / ☁️ クラウド許可中 を切替表示）を追加
    - 設定画面冒頭に「🔒 プライバシー / Strict Local Mode」セクションを追加。状況表示と「クラウド送信許可を取り消す」ボタン
    - AI方法プルダウンの順序を Ollama 先頭に入替
    - `style.css` に `.strict-local-badge` / `.cloud-consent-card` / `.consent-table` / `.consent-agree-row` / `.settings-strict-status` を追加
- **検証：** `node --check static/app.js` 成功。Web Speech / SpeechRecognition / webspeech 参照が全0件
- **効果：** Ver7.0 §1.2 Strict Local Mode の最低限の遵守を達成。クラウド送信は同意なしに発生しないようUIで保証
- **残課題：** サーバー側（main.py）には依然として OpenAI / Gemini への送信ロジックが残る。フロントが同意なしには呼び出さないため即時の Strict Local 違反はないが、防御深度を上げるなら main.py 側でも `cloud_consent` トークンを要求する実装が将来的に望ましい

## 1. 埋め込みPythonを同梱する形に start.bat を改修（2026-03-11）

- **背景：** PC に Python がインストールされていないと起動できない問題があった
- **対応：** `start.bat` を改修し、初回起動時に Python 3.11.9 の埋め込み版を自動ダウンロード・セットアップするよう変更
- **効果：** ユーザーが Python を事前にインストールしなくても `start.bat` をダブルクリックするだけで起動できるようになった
- **仕組み：**
  - `python/` フォルダに Python 埋め込み版を配置
  - `pip` と必要ライブラリは初回のみ自動インストール（2回目以降はスキップ）
  - グローバルの Python 環境を汚さない
