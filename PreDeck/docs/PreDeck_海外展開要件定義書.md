## 1. プロダクト概要・コアUSP

### PreDeckとは
```
「母語でプレゼンを準備して、英語で発表できる」ツール

  母語で録音（日本語・韓国語・中国語・etc）
      ↓
  AIが文字おこし（Groq Whisper・高精度）
      ↓
  AIが母語で原稿を改善・構造化
      ↓
  ワンクリックで英語プレゼン稿に変換
      ↓
  スライドと連動した英語プレゼン練習・完成

この一連のワークフローをローカルアプリ1つで完結させるサービス。
2026年2月現在、世界的にも同等サービスは存在しない。
```

### ターゲットユーザー（グローバル共通）
- 英語が苦手だが、英語でプレゼン・発表が必要なビジネスパーソン
- 国際学会で英語発表が必要な研究者・医師
- 外資系企業・グローバルチームへの転職・就職を目指す方
- 投資家向けの英語ピッチが必要なスタートアップ創業者
- **特にアジア圏（日・韓・台・ASEAN・印）はこのニーズが深刻**

### 3-2. フリープラン（¥0）

#### 対象ユーザー
- PreDeckを試してみたいユーザー
- Ollamaなどの技術的セットアップができる方
- 個人利用で頻度が少ない方

#### 使える機能

| 機能 | 仕様 |
|---|---|
| スライドアップロード | PDF / PNG / JPG（PPTX変換は不可） |
| 文字おこし | **ブラウザ音声認識のみ**（句読点なし・精度並） |
| AI原稿改善 | **Ollamaローカルモデルのみ**（要セルフインストール） |
| セッション保存 | 最大 **5セッション** |
| 練習モード（原稿読み上げ） | ✅ |
| 基本分析（フィラー検出・話速） | ✅ |

#### 使えない機能

| 機能 | 制限（〇〇プラン以上） |
|---|---|
| 高精度Whisper文字おこし（Groq） | スタンダード以上 |
| クラウドAI改善（Gemini / GPT） | スタンダード以上 |
| **英語翻訳・英語プレゼン変換** | スタンダード以上 |
| PPTX自動変換 | スタンダード以上 |
| セッション無制限保存 | スタンダード以上 |
| 原稿クラウド保存・モバイル共有 | スタンダード以上 |
| ピッチスコア詳細分析 | スタンダード以上 |
| プレッシャーピッチモード（AI面接） | プレミアムのみ |

#### フリープランの自然なブレーキ（意図的設計）
```
・ブラウザ音声認識 → 句読点が入らない、専門用語に弱い
・Ollama → 4〜8GBモデルDL必要、RAM 16GB推奨、起動が遅い
・セッション5回制限 → ヘビーユーザーには不足
```
> 💡 **一般ビジネスユーザーが「使いにくい」と感じてスタンダードへ自然移行する設計。「わざと不便にしている」のではなく、技術ハードルが自然な壁になっている。**

## 4. 決済設計（Stripe）

### 4-1. フリープランのクレジットカード登録方針

#### ❌ フリープランにはクレカ不要を推奨

| 観点 | 理由 |
|---|---|
| **登録者数の最大化** | カード登録でCVR（コンバージョン率）が約40〜60%低下（業界平均） |
| **口コミ・拡散効果** | 気軽に試してもらった方がバイラル拡散しやすい |
| **フリーミアムの目的** | まず使ってもらい、価値を体感させてから課金誘導 |
| **競合比較** | Notta・Otter.aiなどもフリーはカード不要 |

#### ✅ 転換率を上げる工夫

```
・フリー5回使い切り → 「続けるにはスタンダードへ」のポップアップ
・英語翻訳ボタン押下（フリー） → 「スタンダード14日間無料トライアル」モーダル
・スタンダード機能境界 → 「このボタンはスタンダード限定」でアップグレード誘導
・毎月1日メール → 「今月の使用回数: 残り0回。スタンダードへ移行しませんか？」
・年払いへの乗り換えキャンペーン（初年度20%OFF等）
```

### 4-2. 推奨する転換設計（Spotifyモデル）

```
フリー（カード不要）
    ↓ 5回で上限 or 英語翻訳ボタン押下
スタンダード14日間無料トライアル
    ↓ カード登録 → 自動継続
¥980/月 スタンダードへ

※ 解約しなければそのまま課金開始（Spotify・Notionと同じモデル）
```
