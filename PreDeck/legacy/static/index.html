☁️ クラウドAPIへの送信について（要同意）

本機能を利用するには、録音・原稿などのデータを 外部クラウド（OpenAI 等） に送信する必要があります。 既定では Strict Local Mode（ローカル処理のみ）です。送信に同意する場合のみONにできます。

送信先 OpenAI API
api.openai.com（HTTPS）
送信データ 音声・テキスト
保存方針 OpenAI のデータ利用ポリシーに従います。デフォルトでは API 経由のデータは学習に利用されませんが、最新の規約をご確認ください。

課金 ユーザーご自身のOpenAI APIキーで直接 OpenAI に課金されます。プレデキ側で手数料は徴収しません。
解除方法 ヘッダー右上の「☁️ クラウド許可中」バッジをクリック、または設定画面でいつでも取り消せます。取り消すとローカル処理に戻ります。
