# 出所について

このフォルダの次のファイルは、メディトク（Meditoku Inc.）の「ちょこっとワークス」音声入力
（`@meditoku/speech-common` および `chokotto-works` の `shared/`）から取り込んだものです。

- `speechRecognition.ts`
- `speechTextFormat.ts`
- `medicalTermPostProcess.ts`
- `punctInfer.ts`
- `rephrase.ts`
- `vocabulary/index.ts`・`vocabulary/types.ts`（シゴトクで拡張）

`format.ts`、`vocabulary/medical.ts`・`science.ts`・`general.ts`、`../asr/` は PreDeck で新規作成したものです。

元コードのライセンス表示は `UNLICENSED`（非公開）です。シゴトクへの権利移転または利用許諾が
書面で整うまで、公開・販売はしないでください。詳細は `PreDeck/docs/ASR-AND-LICENSE-REVIEW.md` を参照。
