# ShapeIt Chrome 拡張 — 開発者モード試用

## いちばん速い使い方

1. `shapeit/app` を起動し **Google で続ける**
2. `shapeit/extension` をビルドして Chrome に読み込み
3. 対象サービス（BuzzIt / ClipIt など）を Chrome で開く
4. 拡張アイコン → 一言入力 → **報告して ShapeIt を開く**
5. Inbox で Todo 化

ショートカット: **Alt+Shift+F**（スクショ付きで Capture を開く）

## ビルド

```bash
cd shapeit/extension
npm install
npm run build
```

Chrome → `chrome://extensions` → デベロッパーモード → 「パッケージ化されていない拡張機能を読み込む」→ `shapeit/extension/dist`
