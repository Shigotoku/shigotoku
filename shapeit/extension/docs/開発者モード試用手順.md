# ShapeIt Chrome 拡張 — 開発者モード試用

詳細は **[セットアップ伴走ガイド](./セットアップ伴走ガイド.md)** を参照してください。

## 最短手順

```bash
cd shapeit/extension
npm install && npm run build
```

Chrome → `chrome://extensions` → デベロッパーモード → `shapeit/extension/dist` を読み込み

1. https://app.shapeit.shigotoku.com で **Google ログイン**
2. 対象 SaaS を開く → 拡張アイコン → 一言 → **この画面から報告する**
3. 受信箱で確認

ショートカット: **Alt+Shift+F**
