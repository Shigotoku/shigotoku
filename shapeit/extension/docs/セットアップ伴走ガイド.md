# ShapeIt Chrome 拡張 — セットアップ伴走ガイド

このドキュメントは、**開発者モードでの試用**から**チーム配布**までを順番に進めるための手順書です。

## 全体像（3つの部品）

```
┌─────────────────┐     postMessage      ┌──────────────────┐
│  ShapeIt アプリ  │ ◄──────────────────► │  content.js      │
│  (ログイン時)    │   SHAPEIT_AUTH 等    │  (アプリページのみ) │
└────────┬────────┘                      └────────┬─────────┘
         │ Firebase ID Token                      │
         │                                        │ chrome.storage
         ▼                                        ▼
┌─────────────────┐     fetch POST       ┌──────────────────┐
│  ShapeIt API    │ ◄─────────────────── │  popup.js        │
│  /v1/feedback   │   Bearer token       │  (どのサイトでも)   │
└─────────────────┘                      └──────────────────┘
```

| 部品 | 役割 |
|------|------|
| `content.ts` | ShapeIt アプリを開いているときだけ動く。ログイントークンを拡張に渡す |
| `popup.js` | 今見ている SaaS 画面のスクショ＋一言を API に直接 POST |
| `background.ts` | スクショ取得、ショートカット、認証更新の仲介 |

**ポイント:** 拡張は Chrome の Google プロファイルとは別です。**ShapeIt にログインしているアカウント**の情報が拡張に渡ります。よく使う Google で ShapeIt に登録・ログインしておくと、以降は SaaS 画面から ShapeIt を開かずに投稿できます。

---

## アカウントのよくある混乱

| 状況 | やること |
|------|----------|
| メールで登録したが、Google で拡張をつなげたい | 拡張に Google を選ぶ画面はない。**そのメールで ShapeIt にログイン**すれば拡張は動く。任意で設定 → Chrome 拡張から Google を**同じアカウントに連携** |
| 仕事用 Chrome プロフィールで拡張を使いたい | **同じプロフィール**で ShapeIt にログインする。個人プロフィールで登録すると、仕事用では未接続になる |
| 接続が切れた | ShapeIt を開いて再ログイン → 設定 → Chrome 拡張 →「拡張へ再接続」 |

使い方ガイド: https://shigotoku.com/shapeit/guide/#account-basics

## ステップ 1 — ビルド（5分）

```powershell
cd shapeit\extension
npm install
npm run build
```

成功すると `shapeit/extension/dist/` に以下ができます:

- `manifest.json`
- `background.js` / `content.js`
- `popup.html` / `popup.js`
- `icon.png`

---

## ステップ 2 — Chrome に読み込む（3分）

1. Chrome で `chrome://extensions` を開く
2. 右上 **デベロッパーモード** を ON
3. **パッケージ化されていない拡張機能を読み込む**
4. フォルダに `shapeit\extension\dist` を指定（`dist` そのものを選ぶ）

ツールバーに ShapeIt アイコンが出れば OK です。

> **注意:** ソースの `shapeit/extension/` ではなく、必ず **`dist`** を選んでください。

---

## ステップ 3 — ShapeIt にログインして接続（初回のみ）

1. https://app.shapeit.shigotoku.com を開く
2. **登録時と同じ方法**でログイン（Google 推奨、またはメール＋パスワード）
3. 設定 → **Chrome 拡張** タブで接続アカウントと「接続済み」を確認

裏側では、アプリが拡張へ `SHAPEIT_AUTH` メッセージを送り、Firebase の ID トークンが `chrome.storage` に保存されます。

---

## ステップ 4 — SaaS 画面から投稿テスト（2分）

1. 報告したい Web アプリ（自社 SaaS など）を Chrome で開く
2. ツールバーの **ShapeIt アイコン** をクリック
3. スクショと URL が自動で入る → 一言書く → **この画面から報告する**
4. ShapeIt の **受信箱** に投稿が入ることを確認

ショートカット: **Alt + Shift + F**（ポップアップを開く）

---

## うまくいかないとき

| 症状 | 確認すること |
|------|----------------|
| 設定で「未検出」 | 拡張が有効か、`dist` を読み込んでいるか |
| 「先にログイン…」と出る | ShapeIt アプリを開き、登録時と同じ方法でログイン。設定 → Chrome 拡張 →「拡張へ再接続」 |
| 送信 401 エラー | トークン期限切れ。ShapeIt タブを開き直してから拡張を開く |
| スクショが取れない | `chrome://` や Chrome ウェブストアは不可。通常の https ページで試す |
| ローカル開発 | アプリは `http://localhost:5178`。manifest の content_scripts に含まれています |

## チームへの配布（zip）

本番ビルド時に zip が生成されます:

```powershell
cd deploy
npm run build:shapeit-extension
```

出力: `deploy/dist/shapeit-app/downloads/shapeit-chrome-extension.zip`

`deploy:shapeit-app` 実行時も自動で同梱されます。

配布手順（メンバー向け）:

1. zip を解凍
2. `chrome://extensions` → デベロッパーモード ON
3. **パッケージ化されていない拡張機能を読み込む** → 解凍フォルダを指定
4. ShapeIt に Google ログイン（初回のみ）

ダウンロード URL（デプロイ後）:  
https://app.shapeit.shigotoku.com/downloads/shapeit-chrome-extension.zip

---

## 開発中の watch モード

```powershell
cd shapeit\extension
npm run dev
```

`dist` が更新されたら `chrome://extensions` の **更新ボタン（↻）** を押してください。

## 次のフェーズ（Chrome Web Store → Workspace 強制配布）

社内本番配布の推奨ルート:

1. Chrome Web Store 開発者登録（**$5 一度きり**、更新は無料）
2. **限定公開（Unlisted）** で申請・公開
3. Google Workspace 管理コンソールで **強制インストール**

詳細チェックリスト: [chrome-web-store申請ガイド.md](./chrome-web-store申請ガイド.md)

### v0.3.0 の主な機能

- 全画面 / 範囲選択キャプチャ
- スクショへの注釈（ペン・矩形・矢印・文字）
- ページ URL・タイトル自動取得
- 編集画面からの再キャプチャ・投稿

社外・不特定多数に配布する段階では追加で:

1. Google デベロッパーアカウント（$5 一回）
2. ストア用スクリーンショット・説明文
3. `host_permissions` の審査用説明（「報告対象ページのスクショ取得のため」）
4. プライバシーポリシー URL

現時点では **開発者モード + zip 配布** で十分です。
