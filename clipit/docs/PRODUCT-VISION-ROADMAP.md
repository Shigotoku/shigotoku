# クリッピット 製品ビジョン・競合・ロードマップ

**更新:** 2026-06-04  
**目的:** 「一度操作を追えば、ある程度の手順書ドラフトができ、後から手直しできる」体験を、コストと選択の自由（自前AI可）と両立する。

---

## 理想体験（ユーザー要望の整理）

| フェーズ | やりたいこと | 現状 |
|----------|--------------|------|
| **記録中** | 画面操作に合わせてスクショ | ✅ Chrome拡張 |
| **記録中** | 話しながらの内容を文字起こし → 説明・注意に反映 | ⏳ Phase 1.5（音声メモ） |
| **記録中** | クリック位置を赤丸（○）で表示 | ✅ 編集画面プレビュー（`StepScreenshotPreview`） |
| **取り込み後** | 手順タイトル・説明・注意のたたき台 | △ タイトル自動・説明は手入力 or **Clipit AI（課金枠）** |
| **編集** | スクショ差し替え・補足画像の挿入 | ✅ 画像アップロード（編集画面） |
| **編集** | マスキング・手順並べ替え・NG/注意タイプ | ✅ |
| **編集** | AIが推敲を手伝う（任意・追加コスト） | ✅ ボタンあり（月間クォータ）／使わない選択可 |
| **編集** | 自社契約の ChatGPT 等で文案を作る | ✅ コピーして外部で編集可能（追加料金なし） |

## 他社サービスにあるか？

**結論:** 海外SaaSの多くは「操作キャプチャ + AI文案 + 注釈」まで揃っている。**音声をそのまま手順説明にする**のは製品により強弱あり。日本向けマニュアル特化はまだ少ない。

| 製品（例） | 操作記録 | AI説明文 | クリック注釈 | 音声→手順 | 日本語・現場向け |
|------------|----------|----------|--------------|-----------|------------------|
| **Scribe** | ✅ | ✅ | ✅ | 限定的 | △ |
| **Tango** | ✅ | ✅ | ✅ | △ | △ |
| **Guidde** | ✅ | ✅ | ✅ | ナレーション系 | △ |
| **Clipchamp / 汎用SCORM** | △ | △ | 手作業 | △ | △ |
| **クリッピット（目標）** | ✅ | ✅（任意課金） | ✅ 赤丸+番号 | **Phase 1.5** | **◎ 前提** |

差別化の軸:

1. **日本の現場**（注意・NG例・賞味期限・既読・縦閲覧）
2. **AIはオプション** — 使わない人は無料枠内で手書き or 外部生成AI
3. **公開前フェイルセーフ**・マスキング・原価設計（`UNIT-ECONOMICS-AND-SECURITY.md`）

## AI・課金の方針（追加料金の考え方）

| 種類 | 課金 | 備考 |
|------|------|------|
| 記録・スクショ・赤丸プレビュー・共有 | プラン月額に含む | AI未使用でも価値が出る |
| **Clipit AI**（かんたん/丁寧/一括生成） | プランごと **月間回数上限**（`BILLING-RULES.md`） | 超過分は将来クレジット購入 |
| 取り込み直後の **自動文案・音声文字起こし** | **Phase 1.5 以降** — 同上クォータ | デフォルトOFF推奨 |
| 外部AI（ChatGPT等）で編集 | **0円** | 説明文をコピーして利用 |

> 使いたくない人は、文章だけ自分の生成AIで作る — この選択肢をUIとドキュメントで明示する。

## 実装フェーズ

### Phase 1（いま）— 記録 → たたき台 → 手直し

- [x] 拡張記録・同一ウィンドウ複数タブ
- [x] 赤丸+番号プレビュー
- [x] 手順画像の差し替えアップロード
- [x] AI文案ボタン（クォータあり）
- [ ] 取り込み時「elementText から1行説明を自動填入」（API軽量・クォータ消費1）

### Phase 1.5 — 話しながら記録

- 拡張 or アプリ: **音声メモ**（Web Speech API / Whisper API）
- 停止時に「音声→各手順の note / instruction 候補」
- 個人情報: 入力値は保存しない（既存方針）

### Phase 2 — 至れり尽くせり編集

- 手順の **挿入**（間に1手順追加・補助画像ステップ）
- 矢印・囲み・NG帯（要件定義書 Phase 2）
- マスク焼き込み API
- PDF サーバー生成

### Phase 3 — 課金・ストア

- Stripe・AIクレジット追加購入
- Chrome Web ストア公開

## 拡張の安定性（0.1.4）

- 記録開始時に **全タブ一括注入を廃止**（chrome:// 等でエラーが出ていた）
- 注入失敗は握りつぶさず **ログのみ**（Service Worker の「エラー」バッジ抑制）
- `manifest` の `type: module` を削除（ビルド形式との不整合回避）
- 未処理 Promise の抑止
