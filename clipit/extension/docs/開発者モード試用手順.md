# クリッピット拡張 — 開発者モード試用手順（未公開・0円）

社内・個人で動作確認しながらアプリを直すための手順です。Chrome ウェブストア登録は不要です。

**前提アカウント:** `meditoku.jp@gmail.com`（Firebase 本番と同じで問題ありません）

---

## 方式の選び方

| 方式 | 向いている人 | アプリURL |
|------|--------------|-----------|
| **A. 本番アプリ**（おすすめ） | まず動かしたい・修正は拡張だけ | https://app.clipit.shigotoku.com |
| **B. ローカルアプリ** | API / アプリのコードも同時に直す | http://localhost:5176 |

初回は **方式A** が簡単です。

---

## 共通：拡張のビルドと読み込み（毎回コードを変えたら）

### 1. ビルド

```powershell
cd clipit/extension
npm install
npm run build
```

`dist/` に次があることを確認: `manifest.json`, `background.js`, `content.js`, `recorder.js`, `popup.html`, `popup.js`

### 2. Chrome に読み込む

1. Chrome で `chrome://extensions` を開く
2. **デベロッパーモード** を ON
3. **パッケージ化されていない拡張機能を読み込む**
4. フォルダに **`clipit/extension/dist`** を指定（`src` ではない）

### 3. コードを直したあと

- `npm run build` のあと、拡張カードの **更新（↻）** を押す
- うまく反映されないときは、一度拡張を削除して `dist` を再読み込み

## 方式A：本番アプリで試す（推奨）

### ステップ1 — ログイン

1. https://app.clipit.shigotoku.com/login を開く
2. **meditoku.jp@gmail.com** で Google ログイン
3. 初回は組織が自動作成されます

### ステップ2 — マニュアルを用意

1. **新しく作る** からマニュアル名を入力（例: 「受付操作テスト」）
2. **空のマニュアルを作成** → 編集画面へ
3. 画面上部の **「拡張と連携」** をクリック  
   - 成功すると **「連携済み」** に近い表示になります  
   - 失敗する場合は下の「トラブルシュート」を参照

### ステップ3 — 記録する業務サイトを開く

1. **記録したい Web アプリ**（電子カルテ・会計など）を開く（同じウィンドウ内の別タブでも可）  
   - `chrome://` や Chrome ストアのページは記録できません
2. 記録したいタブを **アクティブ** にして、拡張アイコン → **記録開始**  
   - **別ウィンドウ**（シークレット含む）のタブは記録対象外です
3. 画面をクリックして操作（**Ctrl+クリックで新しいタブ** を開いても、同じウィンドウなら追従）  
   - 右下に **「● 記録中」** パネルが出ます（新しいタブに切り替えると数秒で表示）  
   - **Alt+Shift+S** でクリックなしの強制キャプチャ  
   - 入力欄を触ると個人情報注意トースト（入力値は保存しません）
4. **記録停止・取り込み** → 自動で編集画面タブが開き、手順が入ります

### ステップ4 — アプリ側で確認

1. 手順一覧・スクショ・赤枠プレビューを確認
2. **AI（かんたん）** や **共有** で続きを試す
3. 問題があればメモ → コード修正 → 拡張 `npm run build` → 拡張を更新

## 方式B：ローカルアプリ + ローカルAPI（開発者向け）

API やアプリも直すときだけ使います。

### ターミナル1 — API（Firebase エミュレータまたは本番API）

**手軽な方法:** 本番 API をそのまま使う（`.env` の `VITE_API_URL` を本番にする）

```env
VITE_API_URL=https://app.clipit.shigotoku.com/api
```

**ローカル Functions を使う場合:** Firebase プロジェクトでエミュレータを起動し、`VITE_API_URL` をエミュレータの URL に合わせる（上級者向け）。

### ターミナル2 — アプリ

```powershell
cd clipit/app
copy .env.example .env
# .env に Firebase の VITE_* を本番値で入れる（.env.example 参照）
npm install
npm run dev
```

→ http://localhost:5176

### 拡張

- 方式A と同じく `dist` を読み込み
- `manifest` / `content.ts` は **localhost:5176** 対応済み
- ログイン・連携は **localhost:5176** 上で行う（本番URLではない）

## 社内の別メンバーに配る

1. リポジトリを clone（または `dist` フォルダを zip で共有）
2. 各自が `npm install && npm run build`（共有 zip の場合は不要）
3. 各自 Chrome で `dist` を読み込み
4. 本番アプリ URL でログイン（meditoku とは別の Google アカウントでも可・組織は別になる）

## トラブルシュート

| 症状 | 対処 |
|------|------|
| 「拡張と連携」しても記録できない | 編集画面で連携を押した **あと**、業務タブで記録開始。本番なら `app.clipit.shigotoku.com` でログイン済みか確認 |
| 取り込み失敗・401 | 連携をもう一度。ログイン切れの可能性 → 再ログイン |
| クリックしても手順が増えない | 記録中か確認。一時停止していないか。`chrome://` ではないか |
| パネルが出ない / 別タブで出ない | **業務サイトのタブ**で記録開始。別タブは **同じウィンドウ** か確認。タブ切替後 1〜2 秒待つ。拡張 **0.1.4** 以上 |
| 拡張カードに「エラー」 | **0.1.5** に更新 → **削除して `dist` を再読み込み** → エラー欄で **すべてクリア**。残る場合は文言をコピーして共有 |
| `signBlob` エラーで取り込み失敗 | API 側の修正が必要。`deploy` で `npm run deploy:clipit-api` を実行してから再試行 |
| popup が動かない | `dist/popup.js` があるか。`npm run build` し直し |
| 別アカウントで Firebase に入れない | CLI は `firebase login:use meditoku.jp@gmail.com`（`docs/FIREBASE-CLIPIT-SETUP.md`） |

### API の疎通確認

```text
https://app.clipit.shigotoku.com/api/health
→ {"ok":true,"service":"clipit-api",...}
```

## 修正ループ（開発の流れ）

```text
1. 現象を再現（本番 or ローカル）
2. clipit/app または clipit/api または clipit/extension を修正
3. 拡張を変えたら: npm run build → Chrome で拡張を更新
4. アプリを変えたら: 本番反映は deploy:clipit / ローカルは dev サーバー再起動
5. もう一度 ステップ2〜4
```
