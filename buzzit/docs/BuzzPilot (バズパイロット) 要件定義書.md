BuzzPilot (バズパイロット) 要件定義書

1. プロジェクト概要

1.1. プロダクト名

BuzzPilot（バズパイロット）

1.2. コンセプト・ビジョン

「SNSツール」ではなく、「売上を作るOS」
「SNS運用を毎朝5分のルーティン作業で終わらせる」「担当者の孤独をなくし、全社員を巻き込む」を実現する、BtoC店舗ビジネス向けのSNS統合管理・自動化SaaS。

1.3. ターゲットユーザー

初期ターゲット (ボウリングピン戦略): 美容室・サロン（1〜数名規模から多店舗展開まで）

拡張ターゲット: 飲食店、パーソナルジム、小規模EC、教育系などのBtoC事業者

ペルソナ: 日々の業務に追われSNSに割く時間がない経営者・店長、またはネタ出しに疲弊し孤立しているSNS担当者。

2. ビジネス要件

2.1. 解決する課題 (ペイン)

何を投稿していいか分からない（ネタ切れ、属人化）。

複数SNSに最適化して投稿する手間が膨大。

既存ツールはグラフが出るだけで「具体的な次の行動」を教えてくれない。

担当者一人に負担が集中し、組織のリアルな知見がSNSに活かされない。

フォロワーは増えても、売上（予約・来店）に繋がっている実感がない。

2.2. 提供価値 (バリュー)

思考ゼロの「処方的生成」: データ分析に基づき「今日やること（この台本を読むだけ）」をAIが指示。

Repurpose（1→多変換）エンジン: 1本のショート動画（台本）から全SNS向けコンテンツを自動生成＆一括予約。

全員参加型フロー: Slack連携で現場のつぶやきをAIが企画化し、摩擦ゼロで投稿キューに追加。

デジタルCV直結: フォロワー数ではなく「LINE友だち追加数」「予約URLクリック数」をKPIとしてトラッキング。

2.3. マネタイズ・プラン設計

Starter (無料): 投稿生成＋台本。※生成物に「Powered by BuzzPilot」の透かし（バイラル用）。

Pro (月額4,980円): 全SNS自動予約、AI改善提案、透かし削除。

Team (月額9,800円) [本命]: Pro機能 ＋ SlackアイデアBot連携 ＋ LINE日次レポート。

Growth OS (月額29,800円): Team機能 ＋ LINE/予約CV計測トラッキング ＋ AI完全自動運用。

3. システムアーキテクチャ・技術要件

3.1. 全体構成方針

禁止事項: スパム判定、アカウント凍結リスク排除のため、スクレイピングおよび非公式APIを利用したデータ取得は一切禁止する。

API統合: 各SNSの複雑な仕様変更を吸収するため、Ayrshare等のSNSアグリゲーションAPIをミドルウェアとして採用する。

3.2. 利用する主要外部サービス・API

SNSアグリゲーション: Ayrshare API (X, Instagram, TikTok, YouTube連携用)

AIエンジン: OpenAI API (GPT-4o / GPT-4o-mini) (台本生成、データ分析、処方的提案)

社内コミュニケーション: Slack API (Block Kit, Events API, Incoming Webhooks), LINE Messaging API

フロントエンド/バックエンド: React / Next.js / Node.js 等 (またはBubble / FlutterFlow等のノーコード/ローコードMVP構築)

データベース: PostgreSQL / Firestore 等

3.3. コスト・パフォーマンス最適化（AI・API）

キャッシュ化: AIのプロンプト結果（成功した投稿の型など）をDBにキャッシュし、類似業種のユーザー間で使い回すことでAPIトークン消費を抑制。

ルールベース分類: 全ての分析をLLMに投げず、ルールベース（しきい値判定など）で一次処理し、必要なものだけAIに推論させる。

キューイングシステム: 各SNS（特にInstagramの自動DM等）のAPIレートリミットを回避するため、ジョブキュー（Redis等）を用いた安全な非同期処理・遅延実行を実装する。

4. 機能要件 (アプリケーション側)

4.1. アカウント管理・オンボーディング

SNSアカウント連携（Ayrshare経由のOAuth認証）。

業種、ターゲット、トーン＆マナーの初期設定。

※プラン管理（Stripe決済連携）。

4.2. SNS経営コクピット (ダッシュボード)

極限までシンプルなUI: 複雑なグラフを排除。

健康スコア表示: 「リーチ(見られているか)」「反応(欲しいと思われているか)」「クリック(売上に近づいているか)」の3指標と総合健康スコアを表示。

今日のミッション（処方的提案）:

AIが「今日はこの【悲報】フック台本で15秒動画を撮影してください」と1画面で指示。

[カメラ起動・録画] または [素材アップロード] ボタンの配置。

4.3. マジック・クリエイター (Repurposeエンジン)

ショート動画起点の入力: 撮影動画、または入力された台本テキストを起点とする。

バズフォーマット適用: 「【悲報】型」「Vlog型」「ランキング型」などのテンプレートを選択/自動適用。

自動多重生成 (1→多):

TikTok / IGリール用: 15秒動画の最適化（CapCut等外部ツール連携、または自社で字幕付け処理検討）。

Instagramフィード用: カルーセル画像用の要点テキスト。

X（Twitter）用: 140文字連投スレッド。

LINE配信/YouTube Shorts用テキスト。

一括予約: プレビュー確認後、1タップでAyrshareへ送信し、各プラットフォームの最適時間帯に予約セット。

4.4. デジタルCVトラッキング機能 (上位プラン)

投稿内のURLクリック計測（独自短縮URLの発行機能）。

LINE公式アカウントへの遷移・登録数の計測（可能であればLINE API連携で正確な数値をトラッキング）。

売上（予約）直結の成果をダッシュボードに反映。

4.5. 勝ちテンプレ市場 (投稿マーケット) ※Phase 2以降

ユーザーのアカウントでバズった投稿（特定されない匿名データ）をフォーマット化。

他のユーザーが「このフォーマットを自社に適用」できる機能。

5. 機能要件 (外部連携・自動化フロー)

5.1. Slack連携：社員参加型「ネタ出し会議」

アイデア受付: 社員が専用Slackチャンネル（例: #sns-ネタ出し会議）にテキストや写真を投稿。

AI自動台本化: Slack Events APIで投稿を検知し、BotがGPT経由で「バズフォーマット化された台本」をスレッドに返信。

社内ウケの可視化: Slackのリアクション（スタンプ）で評価。

ワンタップ採用: Botのメッセージに付与されたボタン（Block Kit）を管理者が押すと、BuzzPilotアプリ側の「今日のミッション（撮影キュー）」に自動追加される。

5.2. デイリーレポート配信 (Slack / LINE)

日次バッチ処理: 毎朝決まった時間（例: 9時）に前日の数値を集計。

レポート生成: リーチ、バズ、クリックの結果と、AIからの「今日の一言アドバイス」をテキスト化。

プッシュ通知: 指定されたSlackチャンネル、またはLINE公式アカウント経由で経営者・チームに送信。

社長承認ボタン: 「この投稿に広告をかけますか？」等の提案に対し、Slack/LINE上で「承認」を押せる機能（Phase 2）。

5.3. リード獲得用：LP連動「無料アカウント診断」

LPにフォームを設置（業種選択、IG/TikTok ID入力）。

バックエンドで該当アカウントの公開基本情報（フォロワー数等）を取得・簡易分析（※公式APIの範囲内、または外部診断ツールAPI利用）。

「AIの辛口アドバイス」と「明日使える台本1つ」を即時生成して画面に表示（またはメール/LINE送信）。

これをトリガーとしたSaaS本登録へのシームレスな遷移。

6. 非機能要件

6.1. UI/UXの原則

「思考コストゼロ」: ユーザーに「次どうするか」を考えさせない。迷うボタンや設定項目を隠す。

ポジティブフィードバック: アプリを開くたび、Slack通知が来るたびに、モチベーションが上がるゲーミフィケーション要素。

6.2. セキュリティ・ブランドセーフティ

炎上防止チェッカー: AIが生成したテキストを自動投稿キューに入れる前に、医療・薬機法NGワードや、過激な表現が含まれていないか判定するフィルター処理。

透かしの強制処理: 無料プランユーザーが生成・ダウンロードするメディアへの「ウォーターマーク」付与のサーバーサイド処理。

6.3. 保守性・拡張性 (アーキテクチャ移行計画)

初期はAyrshareに100%依存して開発速度を優先する。

ユーザー数増大時（Phase 3）、API従量課金コストの最適化のため、Instagramなど最もトラフィックの多いSNSのみ、自社で直接Graph APIと連携するハイブリッド・キューイング構成へ移行できるよう、モジュールを疎結合に設計する。

7. 開発フェーズとMVP (Minimum Viable Product) ロードマップ

Phase 1: MVP（1ヶ月目：コア価値の検証）

目標: 自分たち（RunWith）で使って実績を作るための最低限の機能。

開発範囲:

商材・ターゲット入力 → AIによる15秒動画台本生成。

ショート動画起点 → X/Instagram/LINE用テキストへの自動変換。

Ayrshare経由の手動トリガーによる予約投稿。

極簡易的なダッシュボード（APIからリーチ・反応のみ取得）。

除外: Slack連携、高度な分析、自動レポーティング。

Phase 2: PLG・組織化機能の解放（2〜3ヶ月目）

目標: 美容室向け無料モニター募集、有料化（Pro/Teamプラン）の開始。

開発範囲:

Slack連携（アイデア収集Bot、ワンタップ採用ボタン）。

日次レポートの自動配信（Slack/LINE）。

LP連動の「無料アカウント診断」ロジック実装。

デジタルCV（URLクリック）のトラッキング。

Phase 3: 自律稼働・スケーリング（4ヶ月目以降）

目標: 100社導入、Growth OSとしての完成。

開発範囲:

勝ちテンプレ市場（投稿マーケット）の実装。

プロンプトキャッシュ・SLM移行によるコスト削減。

一部APIの自社内製化（ハイブリッド化）。
