# Xシリーズ自動投稿（Sheets運用の Buzzit 移植）

個人用の「スプレッドシート + GAS + Cloud Functions + X API Free」運用を、Buzzit 内で同等に行う機能です。

## 対応表

| 旧（X自動投稿） | Buzzit |
|----------------|--------|
| スプレッドシートのタブ（A_論文 等） | **シリーズ**（`/x-series`） |
| 投稿OK=○ / 済・未 | **投稿OK（承認）** / ステータス `pending`→`published` |
| スケジュールタブ（曜日・時刻・件数） | **スケジュールルール** |
| GAS 5分トリガー + ジッター | `buzzitPublishWorker`（5分ごと） |
| Cloud Functions `tweet_from_sheet` | `processXSeriesSchedules` + `postTweetWithXApi` |
| X API Free（月500件） | 設定の BYOK + 月次ソフト上限カウンタ |
| 週次メールレポート | Slack 週次レポート（月曜 8:00） |

## セットアップ手順

1. **設定** → X API 連携（API Key / Secret / Access Token / Secret）を保存し接続テスト
2. **Xシリーズ**（サイドバー）→「医療テンプレを作成」で A〜D シリーズ＋ルールを一括作成（任意）
3. 各シリーズにツイートを追加（手入力・クリエイターから追加・CSV）
4. **投稿OK** にチェックした在庫だけが、ルールの曜日×時刻で自動消化される

## アプリ内でリストを作る（推奨フロー）

1. **Xシリーズ** → シリーズを選択（またはテンプレ作成）
2. **一括追加** → **AI一括生成**（1行1テーマ・URL、最大20件）または **テキスト貼り付け**（空行/`---` 区切り）
3. 表表示で内容を確認 → **すべて投稿OK** または行ごとにチェック
4. スケジュールルールで曜日×時刻を設定 → 自動投稿開始

**Magic Creator** からは1本ずつ「Xシリーズへ」追加も可能（`?sns=x` で X 向けに開く）。

在庫パネルに「週N本ペース・約M週分」と表示され、切れる前に補充できます。

**スマホ運用**（PWA・朝5分ルーティン・画面構成）は [MOBILE-UX.md](./MOBILE-UX.md) を参照。

## CSV インポート（既存シートからの移行）

Google スプレッドシートから **ファイル → ダウンロード → CSV** でエクスポートし、シリーズ画面の **CSV** ボタンから取り込みます。

対応ヘッダー例（旧シートと同じ）:

- 投稿OK / ツイートのコメント / タグ / タイトル / X用URL / 画像ALT / 画像URL

`投稿済/未` や `投稿時刻` 列は無視されます（Buzzit 側で投稿後に記録）。

## スケジュールルール

| 曜日の書き方 | 例 |
|-------------|-----|
| 毎日 | 毎日 |
| 平日 | 平日 |
| 土日 | 土日 |
| 複数曜日 | 月水木金 |
| 範囲 | 月~金 |

- **時刻**: `HH:MM`（例 `7:30`）
- **件数**: 1回の発火で消化する在庫数（最大5）
- **ジッター**: 指定時刻からの遅延（分・5分刻み）。旧 GAS と同じ SHA-1 日次ゆらぎ

## 月次上限（X Free）

設定画面に **今月 N / 500** を表示。上限到達時は在庫を `pending` に戻して次回再試行します。

## 運用のヒント

- **Magic Creator** で X 用文案を生成 →「Xシリーズへ」でキュー追加 → シリーズ画面で投稿OK
- 単発の日時指定は **カレンダー** の予約投稿（`x_free` モード）
- 在庫型の繰り返しは **Xシリーズ** のルール運用
