# Buzzit モバイル（PWA）運用ガイド

Buzzit は **PWA（ホーム画面に追加）** 前提です。Xシリーズの「在庫キュー型」運用は、通勤・休憩のスキマ時間で在庫を補充するのに向いています。

## なぜモバイル向きか

| デスクトップ向き | モバイル向き |
|-----------------|-------------|
| 表で大量編集・並び替え | カードで1本ずつ「投稿OK」 |
| CSVの入出力 | AI一括・貼り付けでサッと追加 |
| ルールの細かい調整 | 一度設定したら触らない（自動消化） |

競合の Buffer / SocialDog は「カレンダーに予約」が中心。Buzzit は **承認済み在庫がルールに従って自動で減る** ので、毎日カレンダーを触る必要がありません。

## 初回セットアップ（10分・PC推奨）

1. **設定** → X API 連携（BYOK）と接続テスト
2. **Xシリーズ** → シリーズ作成 or 医療テンプレ
3. **スケジュール** タブで曜日×時刻を設定（例: 平日 8:00 / 12:00 / 18:00）
4. スマホで **ホーム画面に追加**（バナーまたはブラウザの「共有 → ホーム画面に追加」）

以降の日常操作はスマホ中心でOKです。

## 画面構成（スマホ）

### 下部ナビ（常時）

| タブ | 用途 |
|------|------|
| ホーム | ダッシュボード・通知 |
| 作る | Magic Creator（1本仕上げ） |
| **Xリスト** | 在庫の追加・承認（メイン） |
| **解析** | SNSワンタップ解析・グラフ |
| その他 | 予約・設定・詳細分析など |

### Xリスト画面（3タブ）

1. **リスト** — 投稿カード・投稿OK・編集（いちばん使う）
2. **スケジュール** — 曜日×時刻ルール（設定後は月1回程度）
3. **シリーズ** — シリーズの追加・名前変更

上部の **シリーズチップ**（横スクロール）で A/B/C などを切り替えます。数字は「投稿OK」の在庫数です。

### 親指ゾーン（リストタブの下部固定バー）

| ボタン | 動作 |
|--------|------|
| **一括追加** | AI生成 or テキスト貼り付け |
| **全部OK** | 未投稿をまとめて承認 |
| **▶** | 1件すぐ投稿（テスト用） |

フィルター行の 📥📤🔄 で CSV 取込・出力・更新（モバイルのみアイコン表示）。

## おすすめの「朝5分ルーティン」

```
ホーム画面の Buzzit を開く
  → Xリスト
  → シリーズチップで今日補充したい系列を選ぶ
  → 一括追加（AI: テーマを3〜10行 / 貼り付け: メモから）
  → レビューで不要な行をスキップ（Starter+）
  → カードを上からサッと「投稿OK」（または全部OK）
  → 在庫「約N週分」を確認して閉じる
```

**ポイント:** 完璧に仕上げず、在庫を切らさないことが目的。細かい修正はカードの「編集」から。

## シーン別の使い方

### ネタが浮んだ瞬間（30秒）

- **作る** で1本仕上げ → Xシリーズへ追加  
  または Xリストで1行だけ貼り付け

### 週末にまとめて10本（15分）

- PC or タブレットで AI一括（件数はプラン上限）
- スマホでレビュー＋投稿OKだけ行う

### 在庫が少ないとき

- リスト上部の「在庫約N週」を確認
- Pro+ では朝の在庫アラート（Slack/メール設定時）

### 投稿が失敗したとき

- カードにエラー表示 → **再試行** または編集して再承認

## UI/UXの設計方針

- **タップ領域 44px 以上** — 誤タップ防止
- **表は非表示（モバイル）** — カードのみ。横スクロール表は使いにくい
- **モーダルは下からスライド** — 片手操作・キーボード被りを軽減
- **重複ボタンを排除** — 一括操作は下部固定バーに集約
- **PWAバナーはナビの上** — インストール促しと操作バーの重なり回避

## プランとモバイル

| 機能 | Free | Starter+ |
|------|------|----------|
| 貼り付け一括 | 5件/回 | 上限拡大 |
| AI一括 | ✗ | ✓ |
| レビュー before 追加 | ✗ | ✓ |
| 在庫アラート | ✗ | Pro+ |

## SNS解析（モバイル）

競合（Buffer Insights / SocialDog ダッシュボード）を参考に、**ボタン1つで同期＋グラフ**を実装しています。

### 使い方

1. 下部ナビ **解析** を開く（またはホームの紫カード）
2. 媒体タブ（すべて / X / IG / LINE）を選ぶ
3. **解析を更新（同期＋グラフ）** をタップ
4. 「次にやること」カード → 推奨アクションへ直行

### 見られるもの

| 項目 | 内容 |
|------|------|
| KPI | 表示・リーチ・反応・投稿数 |
| ファネル | クリック・LINE追加・売上寄与 |
| 棒グラフ | 媒体別インプレッション比較 |
| 折れ線 | 30日の表示・エンゲージ推移 |
| ランキング | 投稿別パフォーマンス |
| おすすめ | ルールベースの次アクション（Buffer Takeaways 相当） |

詳細の A/B テスト・トレンドは **分析・売上（詳細）**（`/analytics`、マネージャー向け）。

### 追加機能（2026）

| 機能 | 説明 |
|------|------|
| **日次スナップショット** | 「解析を更新」ごとに Firestore に保存。3日以上で長期推移グラフが安定 |
| **Facebook / Threads** | Meta 経由の投稿インサイトを自動同期 |
| **AIサマリー** | Gemini による「次にやること」（解析更新時・`GEMINI_API_KEY` 要） |
| **レポート出力** | PPTX / PDF / HTML ダウンロード + 共有URL（30日・ログイン不要閲覧） |
| **TikTok** | 投稿数のみ表示（Business API 連携は次段階） |
