# X（旧Twitter）自動投稿・予約投稿 ガイド

BuzzIt から X に「時間が来たら自動で投稿」する方法のまとめです。
以前の「Google スプレッドシート + GAS(5分トリガー) + Cloud Functions + X API Free」運用は、BuzzIt にそのまま移っています(対応表は [X-SERIES-AUTO-POST.md](./X-SERIES-AUTO-POST.md))。

## 仕組み(全体像)

```
 あなたの X Developer アプリのキー(4つ) ──► BuzzIt 設定に保存(サーバーのみ・再表示なし)
                                              │
 予約(カレンダー/投稿候補)  ─┐                │
 Xシリーズ(曜日×時刻ルール) ─┴─► 5分ごとのワーカー ─► X API で投稿 ─► 結果を記録
```

- 5分ごとのワーカー(`buzzitPublishWorker`)が、時刻が来た予約と、Xシリーズのルールを処理します。旧GASの5分トリガー + ジッター(投稿時刻のゆらぎ)と同じ考え方です。
- 投稿には **あなた自身の X Developer アプリ(Read and Write)** のキーを使います(BuzzIt が代わりに X API 料金を負担することはありません)。
- 投稿が実行されるのは **予約時刻から最大5分程度** のあとです。

## 事前準備(最初の1回だけ)

1. [X Developer Portal](https://developer.x.com/) でプロジェクトとアプリを作成する
2. アプリの **User authentication settings** で **App permissions を「Read and Write」** にする
   (権限を変えた後は Access Token を **作り直す**。古いトークンは Read のままで投稿に失敗します)
3. 次の4つを控える
   - API Key / API Key Secret(Consumer Keys)
   - Access Token / Access Token Secret(自分のアカウント用)
4. BuzzIt の **設定 → X API 連携** に4つを貼り付け、**「接続テストして保存」**
   → 「接続済み (@ユーザー名)」と出ればOK

### X API の料金(2026年11月に確認)

X API は **従量課金(事前にクレジットを購入)** で、**無料枠・月額プランはありません**(旧 Free / Basic は終了)。

| 操作 | 料金の目安 |
|------|-----------|
| 投稿を作成 | $0.015 / 件(約2円) |
| **URL(リンク)入りの投稿** | **$0.20 / 件(約30円)** |
| 画像メタデータ(ALT)の追加 | $0.005 / 回 |

- 1日1件・リンクなしなら月 約$0.5。**毎日リンク入りだと月 約$6**。リンクは高いので、URL は返信や別の方法に回すと安く済みます。
- 新規は条件付きで最大$20分の無料クレジットが付くことがあります(初回のクレジット購入後)。
- クレジットが 0 になると投稿が失敗します(HTTP 402)。**Developer Console で利用上限(Spending limit)と自動チャージを設定**しておくと安心です。
- 料金は変更されることがあります。必ず [X Developer Console](https://developer.x.com/) の最新表示を確認してください。
- BuzzIt の「今月 N / 500」は、使いすぎを防ぐ BuzzIt 側の安全上限です(課金の上限ではありません)。

## 方法A: 1本ずつ日時を決めて予約する

1. **投稿候補**(またはカレンダー / Magic Creator)で本文を用意する（画像は任意）
   (X 用の本文は 280 字以内。Buffer 経由では `---` 区切りのスレッドは未対応なので 1 本に収める)
2. 媒体で **X** を選び、日時を **未来** に指定して「予約」
3. 時間になると自動投稿されます。カレンダーで結果(投稿済み / 失敗)を確認できます

- 「下書き」にした場合は自動投稿されません。カレンダーで予約に切り替えてください。
- 公式キャラ(承認が必要なキャラ)は、承認されるまで投稿されません。
- カレンダーで、未来の予約は **ドラッグ&ドロップで日付を変更** できます(時刻は詳細で変更)。

## 方法B: Xシリーズ(在庫を曜日×時刻で自動消化・旧スプレッドシート運用の移植)

1. サイドバー **Xシリーズ** → シリーズを作る(旧シートのタブ = シリーズ。A_論文 など)
2. ツイートを追加する(手入力 / AI一括生成 / テキスト貼り付け / **CSV**)
   - 旧スプレッドシートは CSV でダウンロードして取り込めます
     (列: 投稿OK / ツイートのコメント / タグ / タイトル / X用URL / 画像ALT / 画像URL)
3. 投稿したいものに **投稿OK(承認)** を付ける(付いていないものは投稿されません)
4. **スケジュールルール** を追加する(例: 平日 / 07:30 / 1件 / ゆらぎ20分)
5. あとは自動です。投稿済みになると「投稿済み」へ移り、在庫が少なくなると通知(Pro以上)

特定のネタだけ **投稿日時を指定**(scheduledAt)すると、その時刻に自動投稿されます。

## 失敗したとき・注意

| 症状 | 原因と対処 |
|------|-----------|
| 「X API未設定」 | 設定の4つのキーを保存していない。設定 → X API 連携 |
| 認証失敗 / 403 | App permissions が Read のまま、または権限変更後にトークンを作り直していない |
| 「今月のX投稿上限に達しました」 | 月の上限。翌月まで待つか、X 側のプラン/枠を見直す |
| 通知が届くだけで投稿されない | X が未連携のとき、自動投稿ではなく「通知でお知らせ(自分で投稿)」に切り替わる。投稿候補の予約欄に警告が出ます |
| 「Xの利用クレジットが不足」 | X Developer Console でクレジットを追加 |
| 画像が付かない | 画像は JPEG/PNG などの静止画・5MB以内のみ(動画は未対応) |
| 失敗した投稿 | カレンダー / シリーズ画面で原因を確認し「再試行」 |

- 二重投稿防止のため、処理が途中で止まった投稿は自動では再投稿されません。X 側で実際に投稿されたか確認してから「再試行」してください。
- 投稿されるのは **自分のアカウントへの通常投稿だけ** です(いいね・フォロー等の自動化はしません)。

## 無料で使う方法: Buffer 経由(キャラごとに選べる) ※推奨

1. [Buffer](https://buffer.com) の無料プランに登録し、X アカウントを接続する(無料プランは3チャンネルまで)
2. Buffer の設定で **API キー(個人用)** を発行する
3. BuzzIt の **設定 → X API 連携** の「Buffer 経由で X に投稿」にキーを入れ、「チャンネルを取得」→ X を選んで「このキャラの X 投稿先にする」

### 会社の X を、個人の Buffer で運用してよいか

**よいです。** Buffer は「誰のメールで登録したか」ではなく、「どの X チャンネルを接続したか」で投稿先が決まります。メディトク公式 X を Buffer に接続し、そのチャンネルを BuzzIt のキャラに紐付ければ、個人 Gmail で作った Buffer から会社アカウントへ投稿できます。ログインと API キーは社内で引き継ぎできるよう管理してください。手順のまとめは [BUFFER-X-MEDITOKU-SETUP.md](./BUFFER-X-MEDITOKU-SETUP.md) を参照。

- 連携したキャラの X 投稿は Buffer が優先されます(X API の料金はかかりません)。連携していないキャラは、従来どおり X API のキーで直接投稿します。
- 予約時刻になると BuzzIt が Buffer に渡し、約2分後に X へ投稿されます。Buffer 無料プランの「予約は同時に10件まで」は、時刻に1件ずつ渡す方式なので影響しません。
- Buffer 無料プランの API は 1チャンネルあたり 30日で1,000リクエスト(1投稿=1リクエスト)。
- スレッド(複数ポスト)は Buffer 連携では未対応です。
- Buffer の API 利用許諾は「自社の内部連携」向けです。自分のアカウント用に使い、他のユーザーには案内しないでください。
