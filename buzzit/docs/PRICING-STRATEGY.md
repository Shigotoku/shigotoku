- 月20万通まで一律¥3/通、超過分 ¥2.5/通

## 2. 価格設計の論点

### BuzzIt の優位性
1. **Meta直結** — Ayrshare依存が無く、サービス継続性で勝つ
2. **5分朝ルーティン** — 思考ゼロUX
3. **マルチSNS Repurpose** — 1素材から全媒体に同時展開
4. **売上ファネル可視化** — Growth OS = 経営判断ツール
5. **Slack/全社巻き込み** — 中堅以上で他社にない差別化

### 価格上の挑戦
- アピる（¥4,980〜）の **同価格帯 + LINE/Meta直結 + Slack** で機能差別化
- AI-BOUZ（¥22,000一律）の美容特化に対し、**多機能 + 多店舗** で勝つ
- Canly（要見積）の MEO 集約に対し、**店舗単位フリーミアム → 多店舗で上位プラン**

## 3. 価格 3 案

### 案A — 攻めの低価格（市場シェア最優先）

| プラン | 月額 | 主機能 |
|--------|------|--------|
| Free | ¥0 | AI台本、健康診断、月3投稿、透かし、ボイスドラフト |
| Starter | ¥2,980 | 無制限投稿、Meta/LINE自動、透かし削除 |
| Pro | ¥6,980 | Slack連携、承認、GBP連携、LINEセグメント基本 |
| Growth OS | ¥19,800 | Auto Mode、HPB連携、LINEセグメント高度、MEOダッシュ |
| Enterprise | 要見積 | 多店舗・無制限・専任サポート |

**狙い:** アピる・SocialDog の同価格帯を破壊し、月数千店舗の獲得を狙う。  
**リスク:** ARPU低、Growth OS まで誘導できないと収益性が弱い。

### 案B — バランス型（推奨）

| プラン | 月額 | 主機能 |
|--------|------|--------|
| Free | ¥0 | AI台本、健康診断、月5投稿、透かし、ボイスドラフト |
| Starter | ¥4,980 | 無制限投稿、Meta/LINE自動、トレンド波乗り、GBP連携 |
| Pro | ¥9,800 | Slack連携、承認フロー、戦略的通知、LINEセグメント基本、A/Bテスト |
| Growth OS | ¥24,800 | Auto Mode、HPB連携、LINEセグメント高度、MEOダッシュ、売上ファネル詳細 |
| Enterprise | 要見積 | 多店舗管理（〜100店舗）、専任CSM、SLA |

**狙い:** アピるの「はじめて¥0／しっかり¥4,980／いっしょに¥9,980」を真っ向から狙い撃ち、Growth OS で AI-BOUZ・Lステップ・AI-LINE を1本化。  
**特徴:** 美容業界向け機能（HPB連携 / 音声ドラフト）は **Growth OS に標準内包**して AI-BOUZ ¥22,000 と差別化。  
**理由:** **Growth OS（¥24,800）= AI-BOUZ（¥22,000）+ AI-LINE（¥14,800）+ Lステップ・スタンダード相当** の機能集約で、3本まとめて1本化する経済合理性を提示。

## 4. 推奨：案B（バランス型）

### 採用理由

1. **アピる完全包囲** — ¥0 / ¥4,980 / ¥9,800 の3プランで真正面から競合
2. **Growth OS の「3本まとめ」経済合理性**  
   - 美容室が AI-BOUZ ¥22,000 + AI-LINE ¥14,800 を別契約するより安く済む
   - 「3本契約 ¥36,800 → BuzzIt 1本 ¥24,800」で **月¥12,000 削減**
3. **LINE料金改定の追い風** — Growth OS のセグメント配信で配信コストを削減でき、その差額が BuzzIt の料金を相殺
4. **Enterprise でカンリー対抗** — 多店舗・チェーンは別軸の従量制で取りに行く

### 機能配置の根拠

| 機能 | 配置 | 理由 |
|------|------|------|
| AI台本生成 | Free〜 | 入り口（アピる・SocialDog 対抗） |
| Meta/LINE自動投稿 | Starter〜 | 個人店の基本ニーズ |
| Slack連携・承認フロー | Pro〜 | チーム化のトリガー |
| ボイスドラフト | Free〜 | UX で AI-BOUZ に勝つ（音声 → 全媒体） |
| GBP自動投稿 | Starter〜 | Canly/MEO Dashboard 対抗・標準化 |
| HPB連携トラッキング | Growth OS | 美容業界の最終KPI |
| LINEセグメント高度 | Growth OS | 2026秋料金改定の救済策 |
| MEOダッシュボード | Growth OS | Canly対抗（多店舗以外で内包） |
| Auto Mode（完全自動） | Growth OS | 最上位の差別化 |
| 多店舗統合管理 | Enterprise | カンリー直接競合 |

## 5. アップセル戦略

```
Free（5分体験）
  ↓ 投稿数制限・透かし削除欲
Starter（¥4,980 / 個人店の安心）
  ↓ チーム化・承認・Slack需要
Pro（¥9,800 / 小規模チーム）
  ↓ HPB連携・Auto Mode・売上可視化
Growth OS（¥24,800 / 多店舗・美容特化）
  ↓ 100店舗以上・SLA・CSM
Enterprise（要見積 / チェーン）
```

### コンバージョン施策
- Free → Starter: 「月6投稿目で透かしブロック」「自動投稿の14日試用」
- Starter → Pro: 「Slackネタ会議の14日試用」「2人目アカウント招待」
- Pro → Growth OS: 「HPB連携で『どの投稿が予約に繋がったか』を可視化」「LINE配信コスト診断」
- Growth OS → Enterprise: 「店舗数連動の従量プラン提示」

## 7. 経済合理性のメッセージ（営業トーク）

> **「3本契約から、1本へ」**  
> AI-BOUZ + AI-LINE + Lステップ = 月¥58,560  
> ↓  
> BuzzIt Growth OS = 月¥24,800（**月¥33,760 削減**）  
> しかも Meta直結・Slack連携・売上ファネルが全部入り。

> **「LINE料金改定対策パック」**  
> 配信通数を最適化するセグメント配信で、改定後の配信コストを **40〜60% 削減** 可能。  
> Growth OS なら、その削減額だけで月額を相殺できます。
