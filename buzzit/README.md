# バジット（BuzzPilot）

SNS 自動化・組織運営の経営 OS「BuzzPilot（バジット）」のプロジェクト群です。

## フォルダ構成

| フォルダ | 内容 |
|---------|------|
| [`landing-page/`](./landing-page/) | ランディングページ（Astro） |
| [`app/`](./app/) | Webアプリ（React + Vite） |
| [`docs/`](./docs/) | 要件定義・設計メモ |

## 開発

```bash
# ランディングページ
cd landing-page && npm install && npm run dev

# アプリ
cd app && npm install && npm run dev
```
